一、刊行记

  • 舆图既定战区尽易官渡舆图，林冠、变宽笔与史实地物两层贴入，与栅格精确对齐；典籍接十三州全境图，注记按倍率分级。
  • 典籍总揽立文言六门与游戏内纸页，白话细目、出处与疑难点归后台文档，不入界面。
  • 攻城闭环纯逻辑战斗层、城内网格寻路、五维与设施接数值、器械八向，双时钟实时与快照快进同解。
  • 方阵行军框选一队、点一处即收方阵；跨步与速度同源，八向转身、背面三帧重画并逐张自检。
  • 粮草军心常驻短档，严重时只报「约减三成」一类约数，精确数收进折叠细目。
  • 重甲持重收红、留白、纸墨二分；主操作以墨底反金补回重量，不再与常按钮同亮。
  • 零位图逻辑层命令日志、状态指纹、军令帖；无服务器亦可异步对演，逻辑层不进位图与墙钟。

逐版细目、单测与烟测数目、提交级证据见仓库 README 与 docs/；此页只存刊行大要，不铺陈工程流水。

二、体制总揽

章回建安五年八回，依《三国志·武帝纪》《资治通鉴》时序推进，不到史月不回跳。
舆地栅格沙盘与经纬度锚点两套尺度共用投影，格管通行、图管观瞻。
典籍文言六门为经，白话考据为纬；游戏内只读总揽，后台存全本。
军政旬历、资源、设施、武将五维、编队与自动列队，皆入确定性重放。
攻城扎营不等于开打；把兵拖入城中才启战，离营期间各城照常运转。
联机军令帖可脱离服务器传递一局；Transport 可插拔，逻辑三层不迁。
