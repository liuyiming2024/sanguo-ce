## 三、可落地的实现要点（本仓库自撰归纳，非原文摘录）

1. **笔是变宽多边形，不是 `lineWidth`。**
   沿点列每点取切线 → 法向 → 左右各推 `w(i/N)` → 首尾封口 → 一次性 `fill`。`shan-shui-inf.stroke()` 与 `Nonflowers.tubify()` 都是这个结构，**已按 MIT 引入并改写为 `demos/third-party/ink-stroke.js` 的 `ribbon()`**（见 `ATTRIBUTION.md`）。**收笔能收出尖、边缘有墨的厚薄**，逐段设 `lineWidth` 做不到。
2. **先按等弧长重采样（约 4px 一点）。**
   不重采样，飞白噪声频率会随笔画长短变化：长笔飞白稀疏、短笔密集，同一幅里「手感」不一致。控制点先 Catmull-Rom 加密，再等弧长取样。
3. **笔压曲线**。经验式：
   `prof(q) = smoothstep(0, head, q) · (1 − 0.7·smoothstep(1−tail, 1, q)) · (0.85 + 0.15·noise)`
   起笔渐入、收笔减约 70% 宽度、噪声给 ±7.5% 粗细抖动。墨分五色（焦/浓/重/淡/清）对应 tone 约 .9/.8/.6/.35/.15。
4. **飞白：每根笔毛一条连续 path + `butt` 线帽。**
   横向偏移 `±0.475·w·prof`；噪声低于 `dry·q^1.2·0.95+0.05` 时断开，露出的纸即飞白。**坑**：若按「每一小段单独 stroke + round cap」，接头会叠出一节节深点，像竹节或麻绳。
5. **湿芯 / 干笔分层**。整笔先用 ribbon 填湿芯（宽 `w·prof·(1−0.85·dry·q^0.8)`，α≈tone×0.72），越往后越细表示墨将尽；再叠笔毛飞白。纸是底，墨只往上加，不铺满。
6. **运笔节奏**。等时性、2/3 幂律、钟形速度、起落笔与转角顿驻、部件间较长停顿 —— 墨色与运动要一致（停处积墨、快处飞白）。
7. **洇墨**。物理派用 LBM / Fick + 布朗运动 / 三层（表面水、悬浮颜料、沉积颜料）；轻量近似可在抬笔后对笔画做一次局部模糊 + 沿纸纤维方向的羽状扩散。
8. **皴法从山势来，不从格来**。
   取山脊折线 → 按弧长分出笔道起终点 → 方向沿该点法向 → **起笔淡、收笔浓** → 顺同一笔势成组，而非逐格一个三角。皴法类型（披麻长柔曲线 / 斧劈方硬带方向 / 折带 / 雨点）各自是带刚度与方向参数的算子，一幅里不可混用。
9. **笔要读成受光的脊，不是沟**（本仓库 v0.6.0 实验的失败点）。
   脊线本身用亮墨或留水线提光，两侧皴笔由脊向外渐暗、明度与朝向都顺着笔势组织；把一条暗笔叠在等宽等浓的格状皴之上，只会读成划痕。
10. **白描 / 十八描 / 界画**。十八描（高古游丝、琴弦、铁线、钉头鼠尾、折芦、行云流水…）本质是**不同提按与转折的线型**，可参数化为宽度函数；界画用于城郭楼台，靠双勾 + 直尺般的连续长线，不靠贴图。
11. **古舆图的画法依据**（这一条决定「河 / 城 / 道」该怎么摆）：
    - **形象画法**是古代地图主流：见山画山、见水画水，城池村落散布山水之间；虽不追求绝对精确，但「一邑之形势展卷在目」。
    - **传统形象画法地图大都以水系为脉络**，山脉次之；城池村落分布、道路走向、区划分界都以山水为参照。→ 重绘顺序应是**水 → 山 → 道 → 城**，不是先铺格再贴符号。
    - 马王堆地形图：县治用**方框**、乡里用**圆框**，道路细而径直，水道粗细不等而有弯曲，注记位置有定规；《坤舆万国全图》山用青绿山水法、**河流以双曲线表现**。
    - 《平江图》：城墙/宫墙/院墙三级符号，城垛、陆门、水门、拱桥各有定式但按实地位置配置；山用国画习惯画法，树木姿态各异。
    - **计里画方**（《禹迹图》横 70 纵 73 格、每方折地百里；《广舆图》24 个标准图例符号）是「精确但抽象符号」的一路；形象画法保留山水意境。本仓库 144×108 栅格属前者的逻辑骨架，表现层若想有笔意，应向后者取法 —— 两者分家，不是互相替代。
    - 古图常用**超比例压缩 / 夸大重要地物**，故不必强求等比例投影；题识注明「形象画法，纵横不拘实距」即可。

## 四、与本仓库现状的关系

- `README.md` 的 **v0.6.0「一笔山脊实验」**已记录：只挑 `RIDGES[0]` 嵩山一条折线，用 `quadraticCurveTo` 连成路径、笔压 `3.2→0.8` / `.55→.08` 分带重复描，**叠在现有格状皴法之上，一格不删**；实拍差异仅 17px，推近后「那一笔读成划痕而非山脊」，结论是整体退回界画。结论中给出的成立条件正是上面第 9 条。
- 配色清单（v0.5.0 收尾）按「笔势没落定就上色等于给平铺镀金」暂未落地，`styles/main.css` 保持原样 —— 本轮仍不改配色。
- `demos/ink-map-redraw.html` 是**离线整幅重绘实验**，不接入 `src/`，不改 `terrain.js` / `map-data.js` / 存档 / 策略层。它直接读本仓库 `src/map-data.js` 的经纬度锚点，但所有地物都由笔路一次生成，不遍历 `terrain.tiles`。
- `?brush=on` A/B 开关与 `renderer.setBrush()` 保持原状，本实验不触碰。

## 五、下一步（按收益排序）

1. 把 `demos` 里的 `ribbon()/resample()/毛笔飞白` 抽成一个独立 `src/ink-brush.js`，只被表现层调用。
2. 用 `shuimo-core` 的 `generateCunFaStrokes / generateRidge` 跑一组对照，看它的皴笔数据能否直接喂给本仓库的 renderer。
3. 若成立，再把表现层从 `buildBase()` 的逐格静态层里摘出来：格只决定「哪里允许长笔」，笔只决定「长什么样」。
4. 最后才回到 `styles/main.css` 的配色收尾。
