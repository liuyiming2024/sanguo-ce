## 三、重难 · 疑点总揽

1. **官渡小地名在粗格下无法并存**：33° 图幅 / 144 列 ≈ 0.23° 一格，许都—阳翟仅 1.4 格，
   五乘五外墙会互相覆盖、把对方城门变成墙。解法是点城（`cityWalls:false`），不是改坐标。
2. **官渡十二城仍全保留**：id 不改，章回、授简、斥候情报、存档都不串；但全境章回只用其中作为起点的许都、邺作叙事锚。
3. **州治归属是示意**：建安五年辽东公孙、交趾士燮、汉中张鲁、益州刘璋各不相属，
   三色势力只能归并，不可据此读作史实版图；文档后台用，游戏内只给文言一句「州郡棋布」。
4. **图幅与 atlas 对齐**：`createAtlas` 默认 93–126 / 15–43，`project()` 用同一 bounds，
   线性经纬投影逐点对齐；`bg+fg` 两份铺满 3456×2592 离屏，注记不烘进底图。
5. **道路是连通兜底，不是考据官道**：`ROADS` 的 via 折线用于刷地貌，6.6 的直线通行带只保证 A* 可达，
   不代表汉末真实驿道走向；真实走向见 `docs/十三州全境取数表.md` 与 `docs/扩大范围历史地理取数表.md`。
6. **两章的 minTurn**：`config/story.json` 里 ch9=42 / ch10=48 是接在官渡八回之后的史实时序；
   全境开局时装配层重映射为 0 / 6，因为它是另开一局，不是把官渡存演练到第 42 旬。
7. **对面的舆图内核**：`demos/建安五年全境舆图.html` 已由对面自行增量合入 `src/atlas.js`（四档视角、
   双勾水线、按倍率重渲），本轮不重抽、不覆盖 demos，只补了一处 `secTitle` 题名与引言之间的空格，
   让「六门」题名不被文言引言粘成一整句。
