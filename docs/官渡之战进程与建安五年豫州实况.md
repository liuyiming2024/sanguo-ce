## 三、战线与战场工程（可落地为俯视符号）

1. **东西连营**：「依沙塠为屯，东西数十里」「操亦分营与相当」，两军沿鸿沟／官渡水一线呈一字长蛇阵，阵线与水道走向平行。[通鉴网](https://www.dushiwudao.com/?p=20814)、[超星慕课·官渡阵地战](https://mooc1.chaoxing.com/mooc-ans/ztnodedetailcontroller/visitnodedetailcontroller?courseId=201734651&knowledgeId=126881572)
2. **沙堆**：《原阳县志》「袁军主力接近官渡，依沙堆为营攻曹，曹军也立营相距」。沙堆是微地形，不是建筑；画断续短弧笔 + 平顶沙梁。[安阳学院](https://www.ayxy.edu.cn/yyxqtsg_tek/contents/7864/512.html)
3. **土山 / 高橹 / 霹雳车 / 地道 — 长堑**：九月攻防技术对抗，是古代攻坚战法典型战例。[七步雨](https://www.qibuyu.com/bk/107095779.html)、[中国国防报转载](https://k.sina.com.cn/article_7517400647_1c0126e4705905cxwm.html)
4. **烽燧**：居延汉简《塞上烽火品约》十七枚木简，敌 1–10 人「燔一积薪，举二烽；夜二苣火」；积薪重达两吨、外敷泥沙防火、与营房拉开距离；燧长月俸九百钱。[甘肃简牍/酒泉日报](https://k.sina.cn/article_7517400647_1c0126e4705907atge.html)、[甘肃省政府·简牍里的长城](https://ydyl.gansu.gov.cn/gsydyl/gjjl/whsl/202311/t20231124_15756.html)
5. **坞堡**：黄巾后豪强筑坞自守，许褚「聚少年及宗族数千家，共坚壁以御寇」。实物：广州麻鹰岗东汉陶坞堡（国博藏，近方高墙、前后二门、四隅角楼）、武威雷台绿釉陶楼院（中央五层阁、四隅角楼、飞栈通连）。[中国国家博物馆](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_33127.shtml)、[今日头条·绿釉陶楼院](https://www.toutiao.com/article/7157131080598979087/)

## 四、后勤与水文（这一条决定「不画什么」）

- 建安元年（196）用枣祗、韩浩议始行屯田，枣祗为屯田都尉、任峻为典农中郎将，「得谷百万斛」，「军国之饶，起于枣祗而成于峻」；民屯 50 人一屯、军屯 60 人一营，田官不隶郡县。任峻开运粮河故道「西起襄城屯田坡，东经繁城入颍水」，当地称「铜底铁帮运粮河」。[许昌市博物馆](http://mp.weixin.qq.com/s?__biz=MzA3NjkyMzU3Mw==&mid=2659089608&idx=2&sn=6f255f6ae54fca93dc855cae87d00f8b)、[任峻·百度百科](https://baike.baidu.com/item/%E4%BB%BB%E5%B3%BB/10491)
- **建安初黄河剧烈南摆，黄河、济水、汴渠乱流，航道淤塞、漕运中止**。曹操后来治渠「得汴渠之利尤在不通黄流」，刻意避开黄河浑水。[水利部黄委·历史悠久的黄河水运](http://www.yrcc.gov.cn/hhwh/wxyc/202507/t20250722_443934.html)、[郑州档案·魏晋时期的汴渠](http://mp.weixin.qq.com/s?src=11&timestamp=1795005568&ver=7096&signature=3AtlS1xy--sF6LJUm4sIjhduzyhXFuGs1aXddKwnaBlvMDtGpnxBZpTlsm1cV48PQNe7*qUrbhhKZQHjg*6YyJ13LWVBIFfd6kgcsQfjVy*4ggv3WroBB-0AG5YZ*BA&new=1)
- **睢阳渠是建安七年（202）战后所开**，官渡至浚仪段新开、浚仪以下疏浚睢水，目的「转漕给，以保进军河北的军需供给」。[黄委](http://www.yrcc.gov.cn/hhwh/wxyc/202507/t20250722_443934.html)、[超星慕课·曹魏开通的运河](https://mooc1.chaoxing.com/mooc-ans/ztnodedetailcontroller/visitnodedetail?courseId=254300710&knowledgeId=1009869997)
- **结论**：建安五年图上汴渠不通航、睢阳渠不存在。军粮走陆运——任峻以「十路纵队为一部、复阵（两列阵）」护送；徐晃、史涣于故市焚袁军粮车数千辆。[搜狗百科](https://baike.sogou.com/v124743.htm)、[超星慕课](https://mooc1.chaoxing.com/mooc-ans/ztnodedetailcontroller/visitnodedetail?courseId=201734651&knowledgeId=126881572)

## 六、圃田泽与泽缘

《水经注》：「（圃田泽）东极官渡，西限长城，东西四十许里，南北二十许里」；官渡正在泽之东极。郑州鸿沟遗址在荥阳市广武镇（34.952167, 113.469666）；「西限长城」之长城为**战国魏惠王迁都大梁后所筑**，今郑州青龙山庄土岗即其遗址。[水利部黄委·官渡之战话官渡](http://www.yrcc.gov.cn/hhwh/wxyc/202410/t20241015_436810.html)
- 圃田泽「多生蒲草」得名萑苻泽之说与麻黄草说并存，故只作丛生草本、不指定物种。
- **魏长城不画**：战国遗存，至建安五年已荒废三百余年，仅作地名参照。
