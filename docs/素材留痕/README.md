## 与台账的关系

`docs/素材台账.md` 里 10 张 `src/*.jpg` 的「来源」列写的是**无生成记录**，
「是否 AI」列是**待溯源**，「是否入包」列是**不新增引用 / 小程序不进包**。
留痕包补齐哪一帧，就把那一帧在台账里从「待溯源」改成「已溯源」并附上本目录路径；
**没补齐之前不改名**。

## 本轮不做什么
