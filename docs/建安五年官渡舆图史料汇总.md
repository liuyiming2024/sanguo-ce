## 1. 三条硬约束（前几轮已定，不再动摇）

1. **俯视只看顶面**：画面里没有立面建筑，只有平面轮廓与地表纹理。楼阁、飞檐、塔身一律不成立。
2. **背景层不放点景建筑**：背景只铺「地表成因」——林冠、水、沙、田、堤、泽；城郭、关津、
   桥舟、聚落全部归地物层。上一轮删掉山里亭塔，正是这条。
3. **任何新要素必须由连续场或真实经纬度锚点派生**：不许全图撒图章函数。密来自地理，
   不来自重复。

补充一条来自古舆图本身的依据：马王堆《驻军图》把**军事要素用朱红提到第一平面、河流等
地理基础用田青放第二平面**，被称为「分层平面表示法」的早期形态。本实验的三层拆法
（背景/地物/格网）与这个思路同构，不是现代 UI 的凭空发明。

## 2. 古舆图本来就把「景物」当一级符号

这是「能不能加景物」最直接的答案：古图不只画山水城邑，它明确画水利、烽燧、水池、田畴。

是实地，不是补白。

## 3. 本区历史地理（建安五年，官渡一带）

### 3.1 官渡、渠水、鸿沟

《宋史·河渠志三》：「禹又于荥泽下分大河为阴沟，引注东南，以通淮、泗。至大梁浚仪县西北，
复分为二渠：一渠元经阳武县中牟台下为**官渡水**；一渠始皇疏凿以灌魏郡，谓之**鸿沟**。」
即官渡水本身是渠水的一部分。秦时阳武县南有西到洛阳、东达海边的官方大道，北上县衙须渡
渠水，故县在渠水**南岸设官方渡口**，民间称「官渡」。官渡是渡口，不是城。

- **A**｜官渡为渠水南岸官方渡口，官渡水属鸿沟/渠水水系。
- **A**｜阳武县南东西官道确实存在，但按既定「城间不画路线、直接压格子」，**不画**。
- **C（异说）**｜官渡地望有「中牟县东北五里（今中牟官渡镇官渡桥村）」与「今原阳县境」
  两说；方志亦记官渡之战大部分战场在延津境内。本仓库取中牟东北（114.00, 34.55），
  属**近似投影**，不作考古定论。

### 3.2 圃田泽 / 萑苻泽 / 荥泽

《水经注》：「（圃田泽）**东极官渡，西限长城，东西四十许里，南北二十许里**。」官渡正在泽
之东极。圃田泽为豫州九泽之一，属黄河冲积洼地湖，北接黄河滩地，东连蒗荡渠，「水盛则北注，
渠溢则南播」，是黄河与鸿沟水系之间的天然调蓄库。先秦两汉为其水域最辽阔阶段。

- 泽因草木得名：萑苻泽「泽中多生蒲草」，《左传·昭公二十年》「郑国多盗，取人于萑苻之泽」，
  在今中牟东北，与圃田泽东西对峙，中牟城建于两泽之间；亦有说萑苻泽即圃田泽别称
  （「又因芦蒲丛生，亦名萑苻泽」）。**异说并存，图中只作「泽中蒲苇」纹理，不另立专名。**
- 郑州图书馆志书载圃田泽「有**九沟、九泽、二十四浦、二池、三涸**之说」，夏秋北流入渠、
  冬春南注入泽。南北朝后泥沙淤积分割为二十四处相连浅湖，高起滩涂可少量开垦。
  这是「泽中沙洲 + 分割水道」的直接依据，且是**建安五年同时代**的地貌。
- 荥泽：《尚书·禹贡》「荥陂既潴」，济水滞留成泽，西起荥阳以东二十里垂陇城、东至郑州
  五龙口，因与汴河相通，为北渡黄河、东通开封的咽喉；西汉以后渐萎缩。
- 圃田泽南岸有春秋郑文公所筑圃田故城，「圃田泽畔置清邑」即此，中牟称西古城；
  泽西界「长城」为魏惠王迁大梁后所筑魏长城，今郑州青龙山庄土岗即遗址。
- **A**｜圃田泽、荥泽（本仓库 `LAKES` 已有，位置大体合）。
- **B**｜萑苻泽/蒲苇、二十四浦沙洲、圃田故城与魏长城土岗 —— 可入图，需核今地对应。
- **B**｜圃田泽得名另有「泽中多生麻黄草」一说（郑州大学陈隆文），与蒲草说并存；
  图中只作丛生草本纹理，不指定物种。

### 3.3 黄河故道、金堤、水门

- 战国时齐赵魏各距河 25 里筑堤，为下游系统堤防之始；秦汉已成地上河，西汉 180 年间
  大决口 12 次以上。汉人称黄河大堤为「**金堤**」，并不断增修石工、加高增厚。
- 东汉永平十二年（69）王景治河：「商度地势，凿山阜，破砥绩，直截沟涧，防遏冲要，
  疏决壅积，**十里立一水门**，令更相洄注，无复溃漏之患」；自荥阳东至千乘海口修千里大堤。
  水门西汉已发明，王景首次高密度使用（十里一处）。
- **A**｜汉末黄河故道为荥阳北 → 延津 → 白马 → 黎阳 → 东北入冀（本仓库 `RIVER_HUANGHE`
  已按《水经注》所载东汉河道方向拟合）。
- **B**｜沿河**断续夯土堤线 + 间隔斗门**，按 `RIVER_GEO` 弧长派生，不画成等距图章。
- 与本实验关系：现在两岸是青灰湿林（花青），堤是干赭土线，冷暖与干湿都分得开，不会糊。

### 3.4 战场微地形（最贴「景物」的一条）

《原阳县志·大事记》建安五年：「曹操驻军官渡，袁绍军进阳武。八月，袁军主力接近官渡，
**依沙堆为营**攻曹，曹军也**立营相距**。」《延津县志》：「绍率大军渡河，**壁延津南**
与曹军相持不下」「绍辎重囤集**乌巢**」。曹操此前「在官渡一带**筑垒固守**」。

- **A**｜官渡附近有沙堆、土阜；双方依沙堆为营、筑垒立壁。史料原话就是**微地形**，
  不是建筑。背景层应在官渡一带给连续场加一组低矮、断续的沙岗隆起，让林冠变稀、
  露出赭土；夯土垒线本身归地物层。
- **B**｜乌巢粮囤：成组方形屋基 + 晒场，挂一个锚点即可，不铺满。

## 4. 汉末屯田与运粮河（建安五年同时代，最该补的一块）

建安元年（196）曹操迎献帝都许后，枣祗首倡许下屯田，任屯田都尉；「募民屯田许下，
引水以溉」，首年得谷百万斛，遂令郡国置田官。任峻为典农中郎将，邓艾后亦主屯事。

- 枣祗河：起于许昌建安区将官池镇辛集（新集）沟，东经临颍北王岗入潩水达颍河，
  兼灌溉与运粮，通许都南六里南屯粮库。
- 玛瑙河：西起襄城县屯田坡，东经繁城镇入颍水，任峻率军民所开，俗称「铜底铁帮运粮河」。
- 高底河：源于建安区东北尚集镇，流经魏都区东郊，北注入老潩河。
- 灌沟：建安区南、临颍县西，北接颍河、南通玛瑙河；《读史方舆纪要》「**南北二口，
  俱有陡门，亦曹魏时引水灌田处**」。
- 曹操此后又开/整修利漕渠、白马渠、鲁口渠、睢阳渠、贾侯渠、讨虏渠、白沟、平虏渠、
  泉州渠、新河。

- **B**｜许都—颍水一侧的**屯田沟洫**：平行直沟 + 间断陡门，作为低场区的**第三套笔法**
  （前两套是林冠簇、田畴笔）。线状地貌俯视正好，且是建安五年正在发生的事。
- 理由：现在浅田是「浅色短笔 + 淡赭底罩」，与中林略同质感；沟洫一加，低场区立刻
  从「颜色浅」变成「另一种成因」，这是补「地貌种类」而不是补装饰密度。

## 5. 建筑与设施形制（能否入图 / 归哪层）

### 5.1 坞堡 —— 汉末最贴切的一组，归地物层

黄巾后豪强「率勒宗族、宾客、徒附，组织部曲、家兵，**修坞筑堡**」，坞壁成地方武装据点；
许褚聚宗族数千家筑坞壁御敌；董卓郿坞「高厚七丈」，积谷可支三十年。多择「既有山林险阻、
又可农耕」的宜守宜农之地。

形制（出土明器与壁画）：东汉陶坞堡平面近正方形，四周高墙，前后两门设**门楼**，
**四隅角楼**；武威雷台陶楼院四角角楼之间以**飞桥**相连；嘉峪关魏晋墓砖画小城榜题「坞」
字，城上谯楼、城墙雉堞；敦煌悬泉置坞垒方形土坯砌筑、角楼、东向坞门。

> 俯视天然就是「方围墙 + 四角小方块」，最适合航拍。它正好接上 `demos/README.md` 的
> 已知局限：**军屯那一档用坞堡**，市邑/驿另换结构，不再全图同规格小屋。

### 5.2 望楼、阙、庭院（画像砖）——只取平面

东汉宅院画像砖为四合式庭院**俯视图**：四周长廊环列作墙，堂屋面阔三间单檐悬山，
右后院有高层**望楼**（下层有梯、上层有窗，具军事防御功能），另跨院有**水井**、灶、
厨具；凤阙画像砖主阙重檐、两侧子阙、中以桥形屋楼相连。望楼是「东汉官吏富豪宅院的一大
特点」，战乱中豪强营坞壁望楼自保。汉代庭院还常植柏、养鹤、有水田池塘。

- **C**｜阙、堂屋、斗鸡、宴饮、人物 —— **不进图**（叙事画像，且是立面）。
- **B**｜方院 + 一角望楼 + 水井的**平面轮廓** —— 可并入坞堡/聚落符号，不与坞堡重复出现。

### 5.3 「亭」可以平反一半，但必须改形

汉承秦制「**县道大率十里一亭，亭有长**」，刘邦曾为泗水亭长。秦汉的亭是官道边
**带围墙的小院**：大门、土墙、办公厅堂、小客房、马厩，兼治安、驿传、接待；边亭更是
夯土或石垒、红柳芦苇层层叠筑的**瞭望岗楼**，汉简载「高四丈二尺，广丈六尺」等规格，
白天举蓬/烟、夜间举苣火。汉代约 15 公里置一驿。

**四面通透、几根柱子撑屋顶的观景凉亭是魏晋以后文人改出来的**（四大名亭皆唐宋明清）。

> 上一轮「山体里加亭子」被否掉，错在**形制与位置**，不完全错在年代：秦汉确有亭。
> 真要加，画成方形小院 + 一角望楼，挂在关口或道上，**绝不点进山里**，也不画成六角凉亭。

### 5.4 桥渡 —— 现有拱桥其实有点错位

- 战国时单跨/多跨木石**梁桥**已在黄河流域普遍；周文王「亲迎于渭」造**浮桥**，
  《诗经·大雅·大明》为最早记载；公元前 541 年临晋关附近已有黄河浮桥；
  长江上第一座浮桥为东汉建武十一年（35）江关浮桥。
- **东汉已有裸拱**：1957 年河南新野北安乐寨村出土东汉画像砖刻单孔裸拱桥，桥上驷马、
  桥下行船。但石拱桥技术成熟在隋（小商桥、赵州桥一系）。
- 《平江图》305 座拱桥是**南宋苏州**的规格化符号系统。

- **A**｜官渡本身是官方渡口；渡口/码头成立。
- **B**｜黄河、渠水这类水面改为**舟桥/浮桥 + 码头**，而不是江南式石拱；
  现有 `archBridge()` 的拱形宜换成平梁/舟排。这是「纠形」不是「加景」。
- **C**｜成排石拱桥、牌坊 —— 不加。

### 5.5 烽燧、防火水池、渠塘堰井

《驻军图》明确标**烽燧点、防火水池、指挥城堡、防区界线**；《广舆图》明列
「镇寨堡驿、**渠塘堰井**」。汉代边亭燧「燧」为最小单位驻兵 3~5 人，负责瞭望与点火。

- **B**｜烽燧点：归地物层，挂关口锚点（本实验已有烽燧，形制可据夯土墩台校正）。
- **B**｜防火水池/陂塘/水井：小方池或圆池 + 短渠，可并入屯田沟洫系统。

### 5.6 水田、池塘、菱荷（只取俯视纹理）

东汉《弋射收获图》画像砖上层为池塘：莲蓬、游鱼、水鸟、树木，下层收割；成都博物馆
庭院/庄园画像砖有「水田、池塘，栽种秧苗，养鱼和各种水生作物」。汉代陂池水田是常见题材。

- **B**｜只取**成片圆叶、池埂、水汊**等俯视纹理。
- **C**｜弋射、收获人物、飞鸟、游鱼 —— 一概不进（叙事画像，非舆图）。

### 5.7 坟丘与冢柏（可选，少量，作地标）

汉代封土有严格等级：西汉帝陵多为**覆斗形「方上」**（底边 150~230 m、高 26~46 m），
**东汉改圆丘形**，「高度小而直径大」，高不足 20 m、直径 70~130 m；汉代陵墓普遍植柏，
盗伐陵柏弃市。

- **B**｜俯视即「一圈柏树包着浅赭土台」。只放城外、避开泽与深林，**5 处左右**作
  可辨认的地标簇，不撒满。它是给眼睛一个锚，不是填密度。
- **C**｜覆斗形（西汉形制）、山形封土 —— 建安五年不用。

## 8. 最小组合（建议）

不要全加。**背景层只加 4 样**：泽中蒲苇沙洲、官渡沙堆、屯田沟洫、金堤水门；
**地物层补 2 样**：坞堡、渡口浮桥换掉拱桥；坟丘冢柏作可选点缀。

理由：这 6 样全部满足「建安五年此地真有 · 俯视看得见 · 由连续场或真实锚点派生」，
不新增任何可复制图章。而且「空」不是靠撒符号补的，是靠**地貌种类变多**补的 ——
泽、沙、沟、堤、坞、渡各占一种成因，眼睛在同一片林冠里能读出不同的地，就不再往下找底。

## 9. 扩大范围：真实骨架

「地图可以扩大了，但一切都要真实」的执行口径写在独立的
`扩大范围历史地理取数表.md`：给出建议图幅、逐类要素的出处与可信度分级、与
`src/map-data.js` 现有锚点的对应关系、以及「不补什么」。核心原则是
**扩大只增有出处的地物，不用无出处的 filler 填留白**；古舆图允许超比例压缩，
但不允许凭空造城造水。

## 10. 待核与异说（诚实标注，不掩盖）

1. **官渡地望**：中牟东北说 vs 原阳说；战场大部在延津境内的说法。现取近似值，非定论。
2. **萑苻泽**：是圃田泽以东的另一泽，还是圃田泽别称，两说并存 → 图中不另立专名。
3. **圃田泽得名**：蒲草说 vs 麻黄草说并存 → 只作丛生草本纹理。
4. **「辕辕关」字误**：已正名「轘辕关」，见 3.5。
5. **历山**：今地异说多，本仓库 `RIDGES` 的「历山」(115.35, 36.55) 属 C 级，
   扩大时若无法坐实，宜改用有明确记载的太行南段/嵩箕，不强行保留专名。
6. **大野泽**：史实在今山东巨野北，本仓库置于 115.62, 35.42 东北隅属近似，
   扩大到 116.6 时可校正。
7. **水门密度**：「十里立一水门」是王景永平十二年（69）制度，建安五年是否仍完整沿用
   未见直接记载 → 图中作**断续斗门符号**，不宣称精确间距。
8. **东汉裸拱**：新野画像砖证「至迟东汉已有拱桥」，但不代表中原渡口普遍用石拱；
   黄河级水面取浮桥/舟桥更稳。

## 13. 细目考据存目（后台营造用 · 白话，不进游戏）

> 这一章故意**白话、琐碎、逐件**：给改代码的人查形制用。
> 游戏内「典籍总揽」只收文言可诵之文（§14），两者不混。
> 凡此处写「怎么分辨、为什么不加、哪年才有」的，都不出现在界面上。

- **亭子到底长什么样**：汉承秦制「县道大率十里一亭，亭有长」，刘邦做过泗水亭长。秦汉的亭是官道边**带围墙的小院**：大门、土墙、办公厅堂、小客房、马厩，兼治安、驿传、接待；边亭更是夯土或石垒、红柳芦苇层层叠筑的瞭望岗楼，汉简记「高四丈二尺，广丈六尺」，白天举蓬/烟、夜间举苣火，汉代约 15 公里置一驿。**四面通透、几根柱子撑屋顶的观景凉亭是魏晋以后文人改出来的**（四大名亭皆唐宋明清）。所以上一轮「山里加亭子」被否，错在形制与位置，不完全错在年代；真要加就画成方形小院 + 一角望楼，挂在关口或道上，绝不点进山里，也不画六角凉亭。
- **望楼与阙**：东汉宅院画像砖是四合式庭院**俯视图**，四周长廊环列作墙，堂屋面阔三间单檐悬山，右后院有高层望楼（下层有梯、上层有窗，具军事防御功能），另跨院有水井、灶、厨具；凤阙画像砖主阙重檐、两侧子阙、中以桥形屋楼相连。望楼是「东汉官吏富豪宅院的一大特点」。但阙、堂屋、斗鸡、宴饮、人物都是叙事画像 + 立面，**不进图**；只取方院 + 一角望楼 + 水井的平面轮廓，且不与坞堡重复出现。
- **拱桥这件事**：战国时单跨/多跨木石梁桥已在黄河流域普遍；周文王「亲迎于渭」造浮桥，《诗经·大雅·大明》是最早记载；公元前 541 年临晋关附近已有黄河浮桥；长江上第一座浮桥为东汉建武十一年（35）江关浮桥。1957 年河南新野北安乐寨村出土东汉画像砖刻**单孔裸拱桥**，桥上驷马、桥下行船——所以「至迟东汉已有拱桥」成立，但石拱桥技术成熟在隋（小商桥、赵州桥一系）。《平江图》那 305 座拱桥是**南宋苏州**的规格化符号系统。结论：本作删掉 `archBridge()`，黄河/渠水改舟桥 + 码头，这是「纠形」不是「加景」。
- **坟丘的形制换代**：西汉帝陵多为覆斗形「方上」（底边 150–230m、高 26–46m）；**东汉改圆丘形**，「高度小而直径大」，高不足 20m、直径 70–130m。汉代陵墓普遍植柏，盗伐陵柏弃市。俯视就是「一圈柏树包着浅赭土台」，只放城外、避开泽与深林、约 5 处作地标簇。覆斗形（西汉）、山形封土，建安五年不用。
- **烽燧与水池**：《驻军图》明确标烽燧点、防火水池、指挥城堡、防区界线；《广舆图》明列「镇寨堡驿、渠塘堰井」。汉代边亭燧「燧」为最小单位，驻兵 3–5 人，负责瞭望与点火。图上烽燧归**地物层**，挂关口锚点，形制按夯土墩台校正；防火水池/陂塘/水井并入屯田沟洫系统，画小方池或圆池 + 短渠。
- **水田纹理**：东汉《弋射收获图》画像砖上层为池塘（莲蓬、游鱼、水鸟、树木），下层收割；成都博物馆庭院/庄园画像砖有水田、池塘、秧苗、养鱼和各类水生作物。本作**只取**成片圆叶、池埂、水汊的俯视纹理；弋射、收获人物、飞鸟、游鱼一概不进。
- **佛塔为何不加**：白马寺永平十一年（68）已立，汉末《理惑论》有「于洛阳城西雍门外起佛寺……绕塔三匝」，所以不是绝对不存在；但只在洛阳一隅、为西域式精舍，放到官渡豫东平原是地理错位，且塔是立面，俯瞰只余小方块，不值。这条是「时代错位 + 语义错位」，不是「年代错误」。
- **魏长城为何不画**：战国魏惠王迁都大梁后所筑，建安五年已荒废三百余年，仅《水经注》作地名参照（「圃田泽西限长城」）。地名里的「长城」保留，土岗不画。
- **汴渠 / 睢阳渠为何不画**：建安初黄河乱流、漕运中止；睢阳渠建安七年（202）战后方开。本作起于建安五年正月，不能提前画。
- **「禾」形成片庄稼为何不画**：建安五年「白骨露于野」，中原户口约剩十分之一；田畴应是战后荒田，断续稀疏。低场区靠「平行田埂细笔」表达，不靠画庄稼。
- **势力色为何不在背景层**：背景层只管地与物；归属、渗透带、势力名都要随玩家局内状态变化，归上层动态给出。州界朱线是行政区划示意，不是势力。
- **床弩形制（本作美术基准）**：《武经总要》系「平放木床 + 横装弓 + 笔直箭槽 + 床尾绞轴」，弦被绞盘拉回扣在机牙上，是**绷紧的直线**；不是上扬大弯月。比例是「床架一人多高、弓身两米以上」，弩只比人长约 1.5 倍、高约 1.3 倍，旁边站完整甲士作标尺。放大裁切要能数清箭槽、铁翎巨箭、绞轴摇柄、机牙短锤、四个木轮、榫卯横销。全程零柔焦、零缩放雾化、无电影式冷白 rim light、无黑面甲。
- **「毛笔笔势」那次失败的记录**：v0.6.0 曾只挑 `RIDGES[0]` 嵩山一条折线，用 `quadraticCurveTo` 连成一笔、线宽 3.2→0.8 / 浓 .55→.08、折点带分叉枯笔，叠在格状皴法之上。默认全图差异仅 17px（整幅气没变），推近主脊读成「划痕」而非山脊——因为墨色比皴暗，是「沟」的明度关系，且周围等宽等浓的三角皴仍统治画面。结论：**笔与皴的明度、朝向关系没解决之前，单加一笔不成立**。后来改由对面从连续场语法整体重做（见 §12.5），本作直接接入，不再自己试。
- **许可**：引入的变宽多边形笔触原语为 MIT，来源、许可全文与改动清单见 `demos/third-party/ATTRIBUTION.md`、`LICENSE-shan-shui-inf.txt`、`LICENSE-nonflowers.txt`。本仓库 `license: None`，不含第三方图片、字体、数据集；古籍原文只作短句摘引，馆方/政府/学术机构只归纳要点 + 链接。

## 14. 游戏内「典籍总揽」的取舍口径

> 界面是给**玩家**看的，文档是给**营造者**用的。两者共用同一批史料，但文体、粒度、用途完全不同。

| | 文档（本章所在文件 + 其余 docs） | 游戏内「典籍总揽」 |
| --- | --- | --- |
| 文体 | 白话、考据、逐件辨正、链接、表格 | **文言 / 半文言**，短句可诵 |
| 粒度 | 「亭是带围墙小院，不是六角凉亭」「新野裸拱砖 1957 年出土」这类细目全收 | 只写「汉承秦制，十里一亭……四面通透之观景凉亭，魏晋以后始有」，不写出土年份与辨正过程 |
| 用途 | 后台开发时查形制、查出处、判定画/不画 | 增加历史深厚感、给「总的一个浏览」 |
| 数据源 | `docs/*.md`：史料主文档 6 篇 + 核查 / 取数 / 落地 / 证据 / 决策台账，逐项见 §16 | `config/historica.json` → `src/ui-shell.js` `pageArchive()` |
| 可信度 | A/B/C 三级贯穿全文 | 每条右上角一枚 A/B/C 小印，不解释分级含义 |
| 出处 | 完整链接表（§11） | 每条一行短注（篇目或机构名），不贴 URL |
| 异说 | 逐条展开、列今地坐标 | 并入「疑异」门，只写「两说并存，图不立专名」 |

**六门**：本纪（章回时序）/ 舆地（山水城津）/ 图法（古舆图符号）/ 形制（坞堡亭燧桥渡封树）/ 疑异（存疑异说）/ 书目（出处与许可）。

**入口**：「纪事」「天下」「系统」三个文治页顶部各有「典籍总揽」按钮；总揽页底部进「十三州全境舆图」。不新增底部 Tab（移动端竖屏底栏已只露 6 个，再加会更挤）。

**纸 / 墨**：典籍与全境舆图都走 `data-tone="paper"`（蚕白纸页），与武备页的墨底成文武两张脸。**典籍页内**的全境舆图 canvas 自带墨底，只作只读浏览（拖动 / 滚轮缩放 / 放大缩小复位），不挂任何局内指令；另开的**可玩全境图幅**（`?map=quanjing`）不在此列，它复用战区同一套指令、旬历、攻城与存档，只是换了一张图。书目门文言「营造图籍六种」指史料主文档六种，不含后续新增的核查台账、取数表、证据与决策日志；游戏内不列这些细目。

**同步规则**：`config/historica.json` 只增删「可诵之文」；凡新增白话细目、出处链接、落地状态，一律进 `docs/`，**不要**往 JSON 里塞。静态自检会核对六门齐全、每条必带 `t/s/n/lv`、且不出现白话形制词与 URL。

## 15. 重难 · 疑点总揽

> §10 是「待核与异说」，本章是**实施层面的重难**：哪些地方一改就会连锁出问题。按风险排序。

1. **图幅冲突（最高）**：对面有两套图幅 —— 全境 93–126E / 15–43N（`demos/建安五年全境舆图.html`），官渡局部 112.30–116.75E / 32.30–36.95N（`demos/官渡舆图笔势重绘.html`）；本作战区是 112.75–116.15E / 32.65–36.65N。**战区大地图用官渡局部那一套**（`src/guandu.js` `renderGuanduLayers()`），`bg + feat` **两层全份**贴入，按同一 `proj()` 反算 `crop` 窗口精确裁到游戏图幅，城郭 / 关津 / 河防与 144×108 逻辑格天然对齐；上层静态注记（`drawAnnotations`）在 `style==='atlas'` 时让开，只留领地 / 可达 / 军令 / 选中 / 易主旗 / 缩略 HUD，避免重影。**全境那一套现供两处**：典籍页只读浏览（`src/atlas.js`，含三级注记、四档视角与中原详图）与可玩全境图幅（`?map=quanjing`，`src/map-render.js` `style:'quanjing'` 用同一内核 `bg+fg` 铺满整幅）。**仍不要拿全境内核裁一块当战区背景**：它是千公里级笔法，裁下来连续场频率过低、笔宽过粗；战区永远走官渡局部那一套。
2. **笔宽与密度**：`atlas.js` 的笔宽是像素常量，基于自带 1400×1100 离屏。参数化时**不缩放笔宽**，由调用方整幅 `drawImage` 缩放；主画布再按 `camera.scale` 缩回，视觉密度与 demos 定稿一致。若改在 atlas 内部按 W/H 缩放笔宽，全境与战区两套会立刻不同调。
3. **确定性与零位图**：所有随机来自 `rnd(seed)` / `h2()` / `fbm()`，无 `Math.random`、无 `Date.now`、无墙钟、无 `new Image` / `drawImage(位图)`。战区背景与全境页都不得引入位图贴片；同 `seed` 必须逐像素一致。
4. **格网与逻辑不脱钩**：`terrain.tiles` 仍是 144×108 格、15552 格，A*、连通性、领地、点选命中全部绑定它。换背景层只换「地长什么样」，**格仍管哪格是山、哪格能走**。这是 v0.6.0 那次失败换来的分家原则，不能再合回去。
5. **可信度不要升格**：C 级（官渡地望、萑苻泽、麻黄草说、历山、大野泽、水门密度、东汉裸拱、乌巢地望、轘辕字误）一律在「疑异」门并录，不立专名、不称定论、不在图上写死今地坐标。
6. **年代闸门**：睢阳渠（建安七年）、南宋《平江图》语汇、魏晋观景凉亭、隋以后成熟石拱、西汉覆斗形封土——五类都晚于建安五年，任何一处「顺手补一个」都会把时代拉歪。
7. **异说与字误**：`src/map-data.js` 旧「辕辕关」**已正名**「轘辕关」（本轮只改字，`config/historica.json` 与断言均已用正名）；坐标类异说并录不断，逻辑层不动。
8. **许可边界**：MIT 笔触原语的改动清单必须留在 `demos/third-party/ATTRIBUTION.md`；本仓库 `license: None`，不得把馆方图片、PDF 全文、字体文件或第三方数据集复制进 `assets/`。
9. **无预算联机地基**：命令日志 / 状态指纹 / 双路径重放 / 军令帖 base64url 已有，actor 三态 `human/ai/remote` 已预留；但常驻房间、服务器权威时间、账号匹配、防作弊、战斗实时同步都需要常驻服务，**零预算做不到**。不要在史料或界面里暗示「多人已可用」。
10. **游戏内不出现调试语**：双时钟、快进步数、累计逻辑步、快照秒数一律收在「军情细目 · 展开」；典籍页、全境页、toast、日志都用叙事文案，别把工程术语漏进「建安五年」。
11. **全境粗格连通与三色势力是玩法约束，不是史实**：33° 图幅 / 144 列 ≈ 0.23° 一格，五乘五外墙会互相把对方城门盖成墙，故 `cityWalls:false` 点城 + 按 `ROADS` 刻直线通行带保 A* 可达；这不代表汉末真实驿道走向。`cao / yuan / liu` 三色把刘表、刘璋、孙氏、张鲁并作「非曹非袁」，也不是建安五年实属版图。两条白话疑点全留 `docs/全境州郡取数表.md`，游戏内只给文言「州郡棋布」，不得在界面里写成定论。
12. **总揽不许回潮**：§12 实施总纲、§13 白话细目、§14 文白分工、§15 重难、§16 台账是一体的；`scripts/check-map.mjs` 会核对五段标题与「全境仅供典籍页」这类过时措辞。改史料文档后必须跑 `npm run check`，别让文案与实现重新对不上。
