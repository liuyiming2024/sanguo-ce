## 二、小程序这边真正方便与不方便的地方

### 真正省力的部分（架构选对换来的）

1. **逻辑层可以直接搬，而且已经搬完了。** `src/platform/` 把 `storage` / 指针归一 /
   画布节点 / `now`·`randomBytes` 收成四个适配点，`persist.js` 与 `save-slots.js` 是唯二
   真正改过的持久层文件；`scripts/sync-miniprogram.mjs` 从 ESM 依赖闭包镜像 **23 个
   纯逻辑 `.js` 原字节**到 `miniprogram/logic/`，import 路径一字不改，`--check` 实测
   「镜像一致」。`src/` 里唯一实际 `Math.random` 调用仍在 `ticket-store.js`（传帖台短号
   回退源，可注入 `rng`）。清单里「八个可搬、第九个要适配」的判断在 `95d4fad` 时点
   是对的，现在已经闭环。
2. **无构建链。** `index.html` 内联 module 读 `VERSION` 动态加戳，纯静态 Pages，
   没有 webpack/vite 产物要搬；搬家成本只在渲染层。
3. **确定性 RNG 进快照 + 状态指纹 + 命令日志**，天然就是 `onHide` / `onShow` 的解法。
   本轮 `logic-slice.mjs` 已用纯 JSON 存档走过一遍：RNG 快照 `state` + `calls` 能进
   JSON，恢复后 `next()` 序列不分叉。小程序生命周期比浏览器碎，这条比在浏览器里更贴合。
4. **逻辑 / 渲染分离已做实**：渲染层只读位图，不进 state / 存档 / 命令日志 / 状态指纹。
   换皮时逻辑零风险。
5. **素材未就绪整队回退 `soldier.js`**，不白屏。可主动利用：首包做到零 PNG 也能跑，
   不用等资源分包做完才验证。
6. **`config/` 与 `src/` 分离 + `map-data.js` 活绑定**：包体吃紧时先只带官渡本图一章，
   全境图走分包或二期，`config/story.json` 按 `mapId` 裁料即可。
7. **`miniprogram/` 现成的不是战场，但是一条跑通的链路**：1 个页面 +
   `utils/ticket.js` + `utils/relay.js`，军令帖短号中转能传，`tests/miniprogram.test.mjs`
   已在 29 个单测文件里。它证明网络 / 存储 / 页面骨架接得上，只是没接战役层。

### 要实打实做功的部分（不重复绕）

| 断点 | 要做什么 |
| --- | --- |
| `miniprogram/` ≠ 两端跑 | **已有传帖终端 + 最小可玩切片页**，但仍不带战场 / 地图 / 结算。主工程 DOM + CSS + Canvas 2D → WXML/WXSS，**皮要重写** |
| 套壳封死 | 个人主体不能配业务域名，`web-view` 套 H5 走不通，只能原生重写渲染层 |
| Canvas 差异 | 节点获取、DPR / 尺寸、touch 事件、离屏画布接口都不同。「一律 `clientX/clientY` + 实时 `rect` 补一次命中」的手势仲裁经验可复用，代码要改 |
| ESM 加载 | 没有 `<script type="module">`，需要一层很薄的入口适配（**不是**上构建链） |
| 包体 | 抖音主包 ≤4MB / 分包总 ≤20MB。实测 `assets/units/` **33 MB**（52 PNG + 10 JPG 源图，其中 10 张 JPG 只是生成底稿、可不入包），再加官渡 `bg+fg` 与全境 `bg+fg`；必须分包 + 压缩，或先走程序化回退 |
| 存档 | **P1 已解决**：`src/platform/storage.js` 聚合浏览器 `localStorage` 与 `wx` 驱动；`supabase/` 那套单独评估用不用 |
| 测试 | **P5 已补**：30 个单测文件含端侧烟测；CI 是 `node --test` + 浏览器烟测（实测 226 / 163） |

### 最小动作顺序（零方向争议，可与 B 段并行）

- **P1 / P2 / P3 / P5**：对方并行已落地，本轮不再排期；`scripts/logic-slice.mjs`
  作为主工程侧独立复验保留，与端侧切片互为双证。
- **P4（唯一剩下的）**：`assets/units/` 与两张舆图按章分包，首包只带官渡本图；
  未就绪走 `soldier.js` 回退。10 张 `src/*.jpg` 底稿不进包（见 `docs/素材台账.md`）。
- **B5**：补齐 AI 八向帧创作留痕，优先背面三帧；缺的原始记录不能补造
  （见 `docs/素材留痕/README.md`）。
- **B6**：存档规范化把 `undefined` 写成 `{}` / `[]` / `''` 的两处表示差异，需要
  单独一轮 + 全量回归；本轮 `src/` 未改（双时钟核心资产）。

**一句话**：最大的便宜是逻辑层整包已镜像到小程序、双时钟天然贴合端侧生命周期；
最大的误会是「`miniprogram/` 现成 = 顺手两端跑」——皮必须重写，但重写的是皮，不是引擎。
C1 已经落地、P1/P2/P3/P5 也已落地，方向不再悬着；**真正剩下的只有 P4 资源分包、
B5 原始留痕，以及 B6 那两处存档规范化表示差异**。
