## 二、小程序这边真正方便与不方便的地方

### 真正省力的部分（架构选对换来的）

1. **逻辑层可以直接搬，但要说准是哪几层。** `campaign / pathfind / terrain / siege /
   story / formation / direction / condition` 八码注释外零 `document` / `window` /
   `localStorage` / `Date.now` / `performance.now` / `Math.random`——`src/` 里唯一实际
   `Math.random` 调用在 `ticket-store.js`（传帖台短号回退源，可注入 `rng`，单测走注入）。
   **`persist.js` 是第九个、也是唯一需要适配的一个**。这比「能不能跑」值钱，但别把九
   个一起写进「一行不用改」。
2. **无构建链。** `index.html` 内联 module 读 `VERSION` 动态加戳，纯静态 Pages，
   没有 webpack/vite 产物要搬；搬家成本只在渲染层。
3. **确定性 RNG 进快照 + 状态指纹 + 命令日志**，天然就是 `onHide` / `onShow` 的解法。
   本轮 `logic-slice.mjs` 已用纯 JSON 存档走过一遍：RNG 快照 `state` + `calls` 能进
   JSON，恢复后 `next()` 序列不分叉。小程序生命周期比浏览器碎，这条比在浏览器里更贴合。
4. **逻辑 / 渲染分离已做实**：渲染层只读位图，不进 state / 存档 / 命令日志 / 状态指纹。
   换皮时逻辑零风险。
5. **素材未就绪整队回退 `soldier.js`**，不白屏。可主动利用：首包做到零 PNG 也能跑，
   不用等资源分包做完才验证。
6. **`config/` 与 `src/` 分离 + `map-data.js` 活绑定**：包体吃紧时先只带官渡本图一章，
   全境图走分包或二期，`config/story.json` 按 `mapId` 裁料即可。
7. **`miniprogram/` 现成的不是战场，但是一条跑通的链路**：1 个页面 +
   `utils/ticket.js` + `utils/relay.js`，军令帖短号中转能传，`tests/miniprogram.test.mjs`
   已在 29 个单测文件里。它证明网络 / 存储 / 页面骨架接得上，只是没接战役层。

### 要实打实做功的部分（不重复绕）

| 断点 | 要做什么 |
| --- | --- |
| `miniprogram/` ≠ 两端跑 | 只有传帖终端，不带战场 / 地图 / 结算。主工程 DOM + CSS + Canvas 2D → WXML/WXSS，**皮要重写** |
| 套壳封死 | 个人主体不能配业务域名，`web-view` 套 H5 走不通，只能原生重写渲染层 |
| Canvas 差异 | 节点获取、DPR / 尺寸、touch 事件、离屏画布接口都不同。「一律 `clientX/clientY` + 实时 `rect` 补一次命中」的手势仲裁经验可复用，代码要改 |
| ESM 加载 | 没有 `<script type="module">`，需要一层很薄的入口适配（**不是**上构建链） |
| 包体 | 抖音主包 ≤4MB / 分包总 ≤20MB。实测 `assets/units/` **33 MB**（52 PNG + 10 JPG 源图，其中 10 张 JPG 只是生成底稿、可不入包），再加官渡 `bg+fg` 与全境 `bg+fg`；必须分包 + 压缩，或先走程序化回退 |
| 存档 | 本机存档要换成平台 storage API；`supabase/` 那套单独评估用不用 |
| 测试 | 现在 CI 是 `node --test` + 浏览器烟测（215 / 163），端侧要补一套 |

### 最小动作顺序（零方向争议，可与 B 段并行）

- **P1 接入步骤（下一轮单独做）**：新增 `src/platform/` 提供 `storage` / canvas 节点 /
  touch→`clientX,Y` / RNG 注入点；先只让 `persist.js` 改走注入的 `storage`，默认实现仍是
  `localStorage`，保持 215 单测与 163 烟测全绿；再逐模块收口，最后逻辑层连浏览器都不依赖。
- **P2**：先把 `logic-slice.mjs` 这套断言搬成小程序端页面里的「推一旬 → 战报文本 →
  拍快照」最小切片，验证纯逻辑在端里能跑、能读档、能推旬；零 PNG、零 Canvas。
- **P3**：P2 里顺手验「切后台 3 旬回来逐字段一致」，现有双时钟与 RNG 快照直接复用。
- **P4**：`assets/units/` 与两张舆图按章分包，首包只带官渡本图；未就绪走 `soldier.js` 回退。
  10 张 `src/*.jpg` 底稿不进包。
- **P5**：冷启动 → 读档 → 推旬 → 切后台回来一致 → 传帖台短号仍通（复用现成链路当回归）。

**一句话**：最大的便宜是逻辑层里八个模块整包可搬、双时钟天然贴合小程序生命周期；
最大的误会是「`miniprogram/` 现成 = 顺手两端跑」——皮必须重写，但重写的是皮，不是引擎。
C1 已经落地，方向不再悬着；剩下真正没做的是 **B5 原始留痕、P1 适配层、P2 端侧页面**，
以及 B6 那两处存档规范化表示差异。
