## 一、图幅（修正此前口述值）

此前口述 `100~124°E / 21~42°N` 不成立：敦煌郡约 94.7°E、玉门关约 93.9°E、乐浪郡（朝鲜）约 125.8°E、日南郡象林约 16°N 均在框外。

**采用 `93~126°E / 15~43°N`**，纵横各约 33°，近似等距圆柱投影，题识注明「纵横不拘实距」。

## 四、水系（真实锚点折线，一次性路径，不逐格）

- **黄河故道**：金城 → 北地 → 河套 → 武陟 → 新乡/卫辉 → 滑县/白马 → 黎阳 → 东北经馆陶、平原入海。汉末黄河剧烈南摆，济水汴渠乱流，漕运中止。[黄委](http://www.yrcc.gov.cn/hhwh/wxyc/202507/t20250722_443934.html)、[网易·超详细解读](https://c.m.163.com/news/a/HK7RRM9H0543IDY8.html)
- **官渡水／鸿沟**：荥阳北分河，汇蒗荡渠注圃田泽，出泽为官渡水，经中牟分阴沟水与鸿沟水。官渡「北临黄河故道、东有圃田泽、西靠嵩山余脉」为南北咽喉。[黄委·官渡之战话官渡](http://www.yrcc.gov.cn/hhwh/wxyc/202410/t20241015_436810.html)
- **长江**：僰道 → 江州 → 江陵 → 夏口 → 彭蠡 → 建业 → 入海
- **淮水**：桐柏 → 寿春 → 淮阴 → 入海
- **其他**：渭、沔/汉、颍、汝、泗、睢、洮、弱水（至居延泽）、湟水
- **泽**：圃田泽、荥泽、大野泽、云梦、彭蠡、震泽、居延泽

## 六、部族（建安五年时点）

- **乌桓**：辽西、辽东、右北平「三郡乌桓」，蹋顿已统一三部，联袁；207 年白狼山始平。
- **鲜卑**：檀石槐 2 世纪中叶统一诸部，控地东西 14000 余里、南北 7000 余里；**181 年死，联盟瓦解，本图时点为分散各部**——画多个独立小圈，不作单一势力。[中国社科院古代史所](http://lishisuo.cass.cn/xsyj/gdzwgxs/202001/t20200116_5079105.shtml)
- **羌**：凉州羌胡长期扰边，永初四年邓骘曾议弃凉州；武都郡属凉州还是益州，宋代已有《太平寰宇记》与吕祖谦之争。
- **山越**：扬州山地（浙、赣、皖、闽），百越后裔，孙吴后来征讨对象。
- **南匈奴**：并州、凉州一带，于夫罗、呼厨泉曾联袁抗曹。

## 八、南北笔法（「不要太一样」的落点）

秦岭—淮河为 800mm 降水线、1 月 0℃ 等温线、水田旱地分界、北麦南稻、暖温带／亚热带与落叶阔叶／常绿阔叶分界；秦岭北坡 2000–3000m 如挡风墙，汉中、四川盆地降水更丰。[中国气象局·一面黄土一面天府](https://www.cma.gov.cn/kppd/kppdqxsj/kppdtqqh/202111/t20211103_4159392.html)、[腾讯新闻·秦岭淮河](https://news.qq.com/rain/a/20231201A07J4T00)

- **北**：赭黄燥笔、旱田断续稀疏（人口口径）、林冠墨青、田埂短笔
- **南**：河汊成片、方块稻田、植被偏青绿、水网密线
- **巴蜀**：单加茂密层（秦岭挡风）
- **岭南／交州**：疏林 + 骆越部族界，留白多
- **河西／塞北**：沙碛留白 + 长城烽燧，笔数最少
- 三档密度并置：中原 `dense`、边地 `sparse`、玉门以西 `void`
