# 扩大范围 · 历史地理取数表

> 配套文档：`建安五年官渡舆图史料汇总.md`（史料与出处）、
> `毛笔笔势与古舆图参考资料.md`（笔法与许可）。
>
> 回答用户那句「**地图可以扩大了，但一切都要真实**」的执行口径。
> **本文是取数依据，不是已落地的地图数据**：`src/map-data.js` 与 `demos/` 的 HTML
> 在本轮一律未改。下一轮按本表逐条核今地后再写坐标。

## 0. 一条原则

> **扩大只增有出处的地物，不用无出处的 filler 填留白。**

古舆图允许超比例压缩（《平江图》城外湖山、马王堆图邻区压缩皆如此），也允许「形象画法」
把符号画大；但不允许凭空造城、造水、造山。宁可边缘留一点有依据的旷野，也不要为了
「看起来满」补一个查不到的小县城。

因此本表每条都带：**出处 / 可信度 / 与现有锚点的关系 / 是否进图**。
`A` 已用且确定 ／ `B` 史料明确、扩大可用但需核今地 ／ `C` 异说或存疑，不进图。

## 1. 建议图幅（提案值，非史实断言）

`src/map-data.js` 现为：

```js
LON_MIN 112.75, LON_MAX 116.15;   // 3.40°
LAT_MIN  32.65, LAT_MAX  36.65;   // 4.00°
```

建议外扩到：

```js
LON_MIN 112.30, LON_MAX 116.75;   // 4.45°  ≈ 东西多约 115 km
LAT_MIN  32.30, LAT_MAX  36.95;   // 4.65°  ≈ 南北多约  70 km
```

四向各有史料支撑，不是为了对称而扩：

| 方向 | 扩到 | 依据 |
| --- | --- | --- |
| 西 | 112.30（洛阳东 / 虎牢以西） | 虎牢关为「成皋之险，洛阳东门户」；汉末《理惑论》记洛阳城西雍门外佛寺；《宋史·河渠志》荥泽下分大河为阴沟 |
| 东 | 116.75（巨野 / 大野泽、东郡） | 大野泽在今山东巨野北，现置于 115.62, 35.42 属近似，扩大后可校正；濮阳、东郡在此侧 |
| 北 | 36.95（邺北、太行南段） | 邺为袁绍本据、冀州治；太行南段山脊现止于 36.62；黎阳为河北前营 |
| 南 | 32.30（汝南南、颍汝上游） | 汝水现止于 32.70；颍水现起于 33.20；许下屯田区在颍水—潩水之间 |

**栅格影响（必须写进 README）**：144×108 栅格在图幅扩大后，每格代表的公里数变大。
若策略层行军时间仍按 `distKm()` 算，数值不受影响（它按经纬度算），但「每方约百里」
的题识与格网 LOD 的屏幕格距要重新标注一次。`demos/` 的 `proj()` 用同一对 LON/LAT
常量，扩大时需同步，否则预览与逻辑层会错位。

## 7. 道路 / 亭（只作锚点，不绘线）

史料确实有：阳武县南「西到洛阳、东达海边」的东西官方大道；秦律公文传递制度；
汉代「县道大率十里一亭」，约 15 公里置一驿；边亭燧为夯土/石垒瞭望岗楼。

**但按既定口径：城与城之间不画任何路线，`ROADS` 只作符号簇锚点。**

- 亭若加：画成**方形小院 + 一角望楼**（大门、土墙、堂、客房、马厩），挂关口或道上；
  **不是六角观景凉亭**（那是魏晋以后文人改出来的），也**绝不点进山里**。
- 烽燧：夯土墩台，挂关口锚点，可据《驻军图》「烽燧点」校正现有符号。

## 8. 明确不补（防止扩大变编造）

1. 任何查不到出处的县城、河流、山名 —— 边缘宁可留旷野。
2. 佛塔、寺观、牌坊、飞檐楼阁、成排石拱桥、园林凉亭 —— 南宋《平江图》语汇或后世形制。
3. 临晋关浮桥、河北/淮上诸渠 —— 图幅外，不硬拉。
4. 覆斗形封土（西汉形制）、山形封土 —— 建安五年不用，东汉是圆丘。
5. 人物、车马、弋射、飞鸟、游鱼 —— 画像砖是叙事画，不是舆图。
6. 远山剪影与皴法 —— 航拍视角已删。
7. 「官渡原阳说」「萑苻泽另立专名」「泰山余脉」等异说/不一致项 —— 不落为确定数据。
