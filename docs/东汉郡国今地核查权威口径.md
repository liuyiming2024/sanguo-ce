# 东汉郡国今地核查 · 权威口径与边界

> 配套：`东汉郡国今地核查待核清单.md`（125 条点位逐条待核）、`十三州全境取数表.md`、`背景层落地清单.md`。
> 本文只定**什么算权威、什么能进公开仓库、什么必须先停**，不产出任何新坐标。

## 一、结论先行

「大量核查资料必须权威」可以落实，但有一个必须说清的硬边界：**网络公开渠道拿不到 125 个东汉郡国/县邑的逐点今地经纬度**。

谭其骧主编《中国历史地图集》是 8 册、20 个图组、304 幅的纸质图集，收地名 7 万余个，第二册为「秦·西汉·东汉时期」，各册附中英文编例与地名索引[citation:12]。现有的网页化版本是自网络获取原始图片、经地图纠正后用 WebGIS 发布的第三方整理，本身不是授权数据源[citation:12]；而地图著作权受法律保护，未经著作权人许可不得复制、改编、汇编或信息网络传播[citation:11]。CHGIS / 中国历史地理信息平台确实含有秦至清的县级政区数据[citation:13]，但其用户协议限定：仅限非商业学术研究与教育、主要在中国境内使用需复旦大学历史地理研究中心许可、不得从第三方获得数据、不得把数据整体纳入自己的成果、且必须按指定格式注明来源[citation:2]。

因此本轮的处理是：**不臆造、不批发、不把受许可数据搬进公开仓库**。现有 `src/atlas.js` 里 13 个州治、34 个郡治、78 个县邑的经纬度，统一显式降级为「**示意近似值 · 待核**」，逐条列进待核清单；能用权威源给出结论的先给示范，给不出的一律留白并写明需要什么材料。

这与图上已有的两处声明一致：题识「纵横不拘实距」，州界「示意朱线，不作考据边界」。

## 三、四条硬约束

1. **CHGIS 五条**：非商业学术/教育限定；中国境内使用需复旦书面许可；只能从授权网站获取；成果中须清晰标明用了哪部分、如何修改、如何引用；未经管理委员会书面同意不得整体纳入[citation:2]。
2. **图集版权**：谭图、《中华人民共和国国家历史地图集》均受著作权保护，版权延伸使用或出让需事先书面同意[citation:10][citation:11]。本仓库只能写「据某书某卷，某县在今某地」，不能把地名索引或坐标表整份搬进来。
3. **地图合规**：《测绘法》《地图管理条例》规定，境内公开出版、展示、登载地图须报送审核并取得审图号；标准地图可从自然资源部标准地图服务获取，使用时需标注审图号[citation:11]。本实验图是示意图，已声明「纵横不拘实距」与「州界不作考据边界」；若要作为正式地图公开发布，须另走审核。
4. **仓库是公开 GitHub**：以上三条对「推到远端」同样有效。任何受许可数据、图版、索引全表都不进提交。

## 四、逐条核查的字段规范

直接采用《中国历史地名大辞典》的编纂口径——引征有据、尽可能用最早出处、注明版本卷次、标明隶属关系与方位、并增里距[citation:6]。每条记录须填满：

| 字段 | 要求 |
|---|---|
| 县名 | 用《郡国志》原字，异体/讹字单列 |
| 最早出处 | 书名 + 卷次 + 版本（点校本页码或影印本卷叶） |
| 隶属 | 州—郡国—县，按建安五年时点 |
| 方位里距 | 原书里距 + 相对参照（某水某关某城） |
| 今地 | 省 / 市县 / 乡镇，附核定依据（工具书条目或考古报告） |
| 异说 | 并立诸说逐条列出，**不判定** |
| 等级 | S / A / B / C |
| 状态 | 已核 / 待核 / 存异 |
| 核校 | 材料、日期 |

**郡治判定规则**：《续汉书·郡国志》自序明言「凡县名先书者，郡所治也」，即每郡首县即郡治；且该志自述「今但录中兴以来郡县改异」，故郡治迁移须有明确记载才能认定，不能据《汉书·地理志》首县倒推[citation:1]。

**异说处理**：与既有文档「疑异两说并存者，宁并录而不断」一致，`存异` 不得落成确定坐标。

## 五、现在就能用的权威结论（示范）

1. **郡治判定**：用《郡国志》「凡县名先书者，郡所治也」，凡无迁移明文者不得推定移治[citation:1]。
2. **官渡地望两说并存**：一说在今郑州市中牟县县城东北、黄河南岸；另一说据清康熙《阳武县志》、乾隆《怀庆府志》定在原阳县境，本世纪初原阳县大宾镇马头村五佛寺遗址出土《皇经碑记》与《重修碑记》，后者明记建安五年秋九月曹袁在此对峙[citation:4]。图上不选边，只作区间。
3. **乌巢**：《三国志·武帝纪》记「宿绍营北四十里」，裴松之注引《曹瞒传》指明辎重「在故市、乌巢」；《水经注》转引《风俗通》有「渡在中牟」之文。河南党史方志网据此推落在今原阳县阳阿乡查地村一带，并明确写「尚待历史地理学家们作进一步考证」[citation:8]。所以图上只给一处粮囷，不落定点。
4. **时点问题**：谭图修订版计划附逐年行政区划数字版，说明「某年某郡」这类问题须用逐年数据，不能把静态图幅硬套到建安五年[citation:5]。本图的「并州仍独立」「交趾刺史部未改交州」「凉州治所存异」都属这一类。
5. **《水经注》版本**：水系与泽薮引文以陈桥驿《水经注校证》（中华书局）为准，该本参校钞本、稿本三十余种并吸收近代郦学成果[citation:9]。

## 七、需要你定的四件事

1. **是否向复旦大学历史地理研究中心申请 CHGIS 书面许可**——这是唯一能批量拿到县级政区逐点数据的正规路径；拿到之前，125 条点位不能升格为考据坐标。
2. **是否按谭图第二册 + 《中国历史地名大辞典》做人工逐条核校**——125 条加 10 条异说，工作量按条计，可以分批（建议先核 13 州治 + 中原 34 郡治）。
3. **若要把这张图作为正式地图公开发布**，是否走地图审核 / 审图号流程。
4. 在此之前，**是否接受「坐标保持示意，只保证史料、形制与取舍判断有权威出处」**这一口径。当前提交就是按这个口径落的。
