# 素材台账

> B4 落地。口径按清单：**文件 / 来源 / 许可 / 是否 AI / 底图出处 / 是否入包**，逐张溯源；
> **来源不确定的当它不能用**——本轮不擅自删除已在 Web 包里的既有资产，
> 只在「是否入包」里把它们标成「不新增引用 / 小程序首包不带」，并把缺口列成待办。
> 数据取自当前工作区实际文件，sha256 为文件全文前 16 位。

## 待办（来源未闭环，按「当它不能用」处理）

1. 10 张 `src/*.jpg` 的生成方式 / 模型 / 版本 / seed / 提示词 / 迭代稿无记录，**不能补造**（见 `docs/素材留痕/README.md`）。在补齐前不新增对它们的引用，小程序端不进包。
2. 派生 PNG 的可复现链是闭合的（`build_units.py` + `srcSha256`），但「底稿从哪来」这一环没闭合；台账里如实标「待溯源」，不写成「已核实」。
3. 小程序 P4 分包时，先剔除 10 张 JPG 底稿，再按章切 `bg+fg` 两张舆图。
