# 背景层落地清单（建安五年舆图）

> 与《官渡之战进程与建安五年豫州实况》《十三州全境取数表》配套。每条只判定「画 / 不画」，并给依据。
> 三条筛子不再动摇：俯视只看得见顶面和平面轮廓；背景层不放点景建筑；任何新东西都由连续场或真实锚点派生，不许全图撒图章。

## 三层结构

| 层 | 内容 | 开关 |
|---|---|---|
| 背景层 | 纸、图廓、水系、连续地貌场、林冠／田畴／沙碛笔、脊线林相、泽缘草本 | 始终画；按倍率分档重渲 |
| 地物层 | 州治／郡治分级符号、城郭、关津、烽燧、坞堡、桥舟、对峙阵线、战场工程 | 「地物层」 |
| 工笔层 | 屏幕空间双勾细笔（成簇、笔型四变、约两成带水线），放大渐显 | 「工笔」 |
| 上层 | 逻辑界格 + 分级注记 | 「压上格子」，默认压上，缩小按 LOD 退场 |

背景层不出现居民点与点景建筑。密度来自「地貌种类变多」，不来自复制图章。**势力归属完全不画**，由上层按局内状态动态给出；本表只管地与物。

主景分两级：一级朱题只给三处（官渡连营、雒阳灵台、居延积薪），靠朱色 + 竖排 + 字级 + 不规则淡纸衬点明重点；其余十处为二级墨注，有辨识度但不抢。所有主景各自单独绘制，不用同一图章循环。

## A 组 · 背景层，可画

| 景物 | 判定 | 依据 |
|---|---|---|
| 圃田泽蒲苇 + 沙洲 + 二十四浦 | 画 | 《水经注》「东极官渡，西限长城，东西四十许里」；志书载九沟九泽二十四浦。由 WET/OPEN 场派生，沙洲为低湿孤岛，蒲苇顺洲缘一次性游走 |
| 官渡沙堆 | 画 | 《原阳县志》「依沙堆为营攻曹，曹军也立营相距」。独立 SAND 连续场，断续短弧笔 + 平顶沙梁，不画实线坡脚 |
| 许下屯田沟洫 + 陡门 | 画（稀疏） | 建安元年枣祗、任峻屯田「得谷百万斛」；灌沟「南北二口，俱有陡门」；任峻运粮河「西起襄城屯田坡，东经繁城入颍水」。挂 CANALS 锚点，陡门只在部分沟口；密度按人口锐减口径压低 |
| 黄河金堤 + 水门 | 画（断续） | 汉代黄河系统堤防称金堤，王景「十里立一水门」。沿 RIVER 弧长铺断续夯土线；建安五年是否完整沿用无直接记载，故不画成等距闸门阵列 |
| 泽缘芦苇 / 河岸汀渚 / 水汊 | 画（**不填色片**） | 古舆图以水系为脉络，见山画山、见水画水；《广舆图》明列渠塘堰井、古河道为一级符号。实现上删掉青色椭圆填充与白沙洲椭圆，只留断续岸笔 + 顺流水纹 + 芦苇丛 + 浅色短横，水由底罩湿场的偏青底从纸里透出来 |
| 秦岭、太行、阴山、祁连、南岭 | 画（**只留林相，不画山形**） | 全境尺度下山脉是千公里级地理骨架，秦岭—淮河为 800mm 降水线与南北笔法分界；但航拍俯视只见林冠，灰色山脉带与栅栏式顺坡皴在放大后会读成几何山形，本轮整段删除，改由脊线散点短笔 + 随倍率加密的顺坡细皴暗示山势走向 |
| 烽燧（长城沿线） | 画（地物层） | 《塞上烽火品约》，积薪、苣火、烽竿、坞垣、角楼；复用 `beacon()` 语义 |
| 长城三重 | 画（地物层） | 秦长城西起临洮东至辽东；汉武帝西延至玉门关、沿弱水至居延泽；太初三年徐自为于阴山河套北筑两道平行外长城（光禄塞、居延塞）。遗迹约三千五百公里，石砌／土筑／红柳夹沙 |
| 邙山冢丘柏丛 | 画（少量地标簇） | 东汉封土由覆斗形改圆丘形，「高不足 20 米、直径 70~130 米」，汉陵普遍植柏。俯视为一圈柏树包浅赭土台，只放城外、避开泽与深林 |
| 蜀郡临邛火井 | 画（二级墨注） | 汉代蜀郡临邛已见火井（天然气井）记载，扬雄、左思《蜀都赋》及后世地志相承。俯视为井口 + 井架 + 一点幽火，不是普通屋舍 |
| 会稽鉴湖 | 画（二级墨注） | 东汉顺帝永和五年（140）会稽太守马臻主持修筑，为江南早期大型陂塘水利。俯视为不规则湖面 + 断续堤塘 + 斗门 |
| 黄河下游沙碛 | 画（背景层） | 建安初黄河剧烈南摆、故道沙地；官渡「依沙堆为营」。连续场高值区才换极稀平顶短弧，不连成沙带 |
| 海积平原 | 画（背景层） | 青徐扬东缘沿海滩涂与盐田；岸线随纬度与低频噪声摆动，偏青灰盐田短笔、时有缺笔 |
| 零陵桂阳喀斯特 | 画（背景层） | 南岭南麓峰林，只在小片高值区以两三笔一组的孤峰点簇出现，不成片、不是三角阵列 |
| 雒阳灵台／明堂／辟雍 | 画（一级朱题） | 东汉雒阳城南礼制建筑群，灵台为太史令候望之所（张衡曾掌）。俯视为不规则夯土高台 + 环柏 |
| 阳城汉三阙 | 画（二级墨注） | 太室、少室、启母三阙，东汉延光年间石阙实物，在颍川阳城一带。俯视为一对石垛，中留阙道 |
| 轘辕关十二曲 | 画（二级墨注） | 轘辕山道十二折，`src/map-data.js` 旧作「辕辕关」为正名。用一条折返十二次的一次性笔路 |

## B 组 · 地物层，可画但须纠形

| 景物 | 判定 | 依据与纠形 |
|---|---|---|
| 坞堡 | 画 | 只给官渡、黎阳、白马、延津等有史料依据的前线据点。方围墙 + 四隅角楼 + 一门楼；**不是**楼阁宅院 |
| 秦汉之「亭」 | 画（方院） | 汉承秦制「十里一亭」，为带围墙小院（门、土墙、堂、客房、马厩），兼治安驿传；四面通透的观景凉亭是魏晋以后。**不点进山里** |
| 乌巢粮囤 | 画（一处） | 「绍辎重囤集乌巢」，成组粮**囷**（汉囷为圆，非方屋）+ 晒场。实现上半径／间距／弧长各自独立的断续囤笔，不画一排同款闭合圆 |
| 舟桥／浮桥 + 码头 | 画（替换石拱） | 官渡本为官方渡口；汉代以木石梁桥、浮桥为主，黄河上早有浮桥。删掉江南式 `archBridge()` |
| 对峙阵线 | 画 | 八月「依沙塠为屯，东西数十里」「操亦分营与相当」，深沟高垒；官渡水两侧两道断续长壕 + 沙堆短弧 + 断续营弧笔（`campArc()` 缺口各异、大小不等、部分营不画），曹营偏深绿、袁营偏赭黄 |
| 战场工程 | 画 | 九月土山高橹、霹雳车发石、地道—长堑；沙岗顶端密笔、曹营侧离散石堆、两道平行浅壕 |

## C 组 · 明确不画

| 条目 | 理由 |
|---|---|
| 魏长城土岗 | 战国魏惠王迁都大梁后所筑，建安五年已荒废三百余年，仅《水经注》作地名参照 |
| 佛塔、寺观 | 白马寺虽永平十一年（68）已立，仅洛阳一隅、西域式精舍，且为立面，俯瞰只余小方块 |
| 飞檐楼阁、牌坊、园林亭、成排拱桥 | 《平江图》式南宋城市图语汇，非汉末中原 |
| 山体里的亭子、塔、寺、村舍 | 层次错位：这是 `buildBase()` 背景层，不是完整文人山水 |
| 城间道路线 | 按既定「直接把格子压上去」，背景只作地形 |
| 远山剪影、皴法、空灵山态 | 航拍俯视只见林冠；山势由林冠明暗与沟谷暗带读出 |
| 汴渠通航、睢阳渠 | 建安初黄河乱流漕运中止；睢阳渠建安七年（202）战后方开 |
| 西域诸国、海南 | 西域止于玉门关；珠崖已罢。画进来会把图变成东亚全图 |
| 「禾」形成片庄稼 | 建安五年「白骨露于野」，中原户口约剩十分之一；田畴为战后荒田，断续稀疏 |
| **势力归属 / 渗透带 / 势力名** | **归上层逻辑**：与玩家局内动态相关，不由背景层决定。州界朱线是行政区划示意，不是势力 |

## 已知局限（不掩盖）

- 双勾轮廓与留水线已实现（工笔层 + `brush(hook)`），但只给约两成笔，不是全图白描；若要严格工笔还需把分区平涂改成逐层薄罩。
- 黄河在全境尺度下仍是单线双勾，纸白芯已压暗；支流以断续短笔示意，不作双勾河岸的写实复原。
- 州界碎化后极淡，几乎只剩界标感。
- 官渡沙堆在纯背景里偏像干赭斑；断续短弧笔已改善边缘，仍不如真实沙岗有形。
- 城外聚落仍略同规格；古舆图本用规格化符号（《平江图》三百桥同一拱形），若要更活应按军屯／市邑／驿换结构。
- 郡治与约 80 个县邑今地坐标为示意近似值，105 郡国级地名未全量核异说；接回 `src/` 时顺手修已知字误与旧坐标、跑 `validateMap()` 即可。
- 边地（河西、辽东、日南、乐浪）史料密度低，留白大是有意的，不是没画满。
