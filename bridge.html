短号代整帖 · 一旬一传

此页只作传递，不入局、不重放、不推进旬历。刊本 —。

一、接续

填入你自己的项目地址与 anon public key，只存在本机浏览器，不写进仓库、不随页面发出。anon key 按设计可公开；service_role key 绝不要填，页面会直接拒收。

首次使用请先在 Supabase SQL Editor 执行 supabase/schema.sql；表未建、RLS 未开、CORS 未放行，都会在这里报出原始状态，不静默吞错。

二、发帖

从游戏「系统 → 导出军令帖」复制整段口令，换取六位短号。短号发给对方即可，整帖留在库里，七日为期。

四、凡例

短号是取件码，不是密码：拿到即可读帖，库里存的是明文军令帖，别往帖里放凭证或个人信息。匿名可写意味着任何人都能提交短号，免费层不自带速率限制；七日过期行由读侧过滤，不会自动消失。

小程序端不直接访问外部服务，只在会话里传短号或整帖；外部域名需由本主体备案才能配进 request 合法域名，第三方项目域名做不到。完整口径、表结构、成本与未闭环项在后台文档。
