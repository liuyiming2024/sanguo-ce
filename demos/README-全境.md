## 打开

浏览器直接打开 `建安五年全境舆图.html`（自包含，无外部依赖、无位图）。

- 滚轮缩放 / 拖动平移
- 「重落一笔」换 seed 重画
- 「地物层」切地物显隐
- 「工笔」切屏幕空间双勾细笔层（放大时渐显）
- 「压上格子」默认压上，缩小按 LOD 退场
- 「中原详图 / 返回全境」一键切到官渡—许都一线的大局部（×2.70）
- 「放大 / 缩小 / 复位」

| 层 | 低倍率 | 高倍率 | 关键 |
|---|---|---|---|
| **格网** | ×0.29 全隐 → ×0.61 主格 → ×1 全显 | 线宽按 `1/z` 补偿，恒定粗细 | 缩小防密 |
| **注记** | L1 州治 + 3 朱题 | L2 郡治/州界/墨注 → L3 汉末县邑 | 屏幕固定字号，不随缩放糊掉 |
| **背景笔** | 离屏 1× 渲染 | 跨档重渲（×2/×3），笔在逻辑坐标里缩小加密 | 放大不把笔拉成鱼鳞 |

**注记分级**：文字不烘进离屏图层，按屏幕固定字号绘制，只按倍率做 `0.90~1.18` 微调和档位切换。

| 档 | 触发 | 显示内容 |
|---|---|---|
| **L1** | 全境 ×1 及以下 | 13 州治 + 3 处一级朱题 |
| **L2** | `zoom≥1.15`（详图下 `≥0.85`） | + 郡治、州界名、10 处二级墨注 |
| **L3** | `zoom≥2.00`（详图下 `≥1.30`） | + 约 80 个汉末县邑 |

- **碰撞避让**：按 `朱题 > 州治 > 州界 > 郡治/墨注 > 县邑` 依次落字，包围盒相交的下级自动跳过。密处少显、疏处多显。
- 详图模式放宽阈值但**不锁死**：继续缩小，注记照样逐层收起（实测 ×2.70 → ×1.01 由 L3 退回 L2）。
- 详图时图廓题识被移出视口，补屏幕固定题签「中原详图 · 官渡至许都」。

**背景按倍率重渲**是本轮最关键的一处。此前背景是固定 1400×1100 的离屏 canvas，×2.7 放大只是把像素拉大，短笔被拉成整齐的鱼鳞斜纹——那正是「平铺感」在大局部下的复发。现在 `makeBg(zb)` 在跨档时重算：笔触在逻辑坐标里按 `k=1/zb` 缩小加密，离屏图超采样 `S=ceil(zb)` 倍保证清晰，合成后屏幕笔宽 ≈ 原尺寸。滚轮/拖动仍只做即时合成，重渲只在倍率跨整数档时发生。

**三级县邑**为《续汉书·郡国志》司隶河南尹/河内、兖州陈留/东郡、豫州颍川/汝南/梁/沛/陈、冀州魏郡的真实县名（中牟、阳武、酸枣、浚仪、雍丘、长社、召陵、苦、下邑、鄄城、馆陶、野王、荥阳、故市……），今地坐标为示意近似值；接回 `src/` 时顺手修已知字误与旧坐标即可。

## 工笔层：双勾 + 水线

`brush()` 增加 `hook`：沿笔的左右缘各描一线，内缘留一道纸白「水线」。**不是给笔加框**——缘是笔自己的边界，随提按收尖，那道白是染与线之间的留隙。

屏幕空间另起一层 `drawInkDetail()`，反算地理坐标决定笔型、方向、疏密（笔跟着地走，不跟屏幕漂），`zoom≥1.45` 渐显：

- **成簇不铺满**：低频簇场 `fbm<.535` 整片跳过，簇心概率落笔；放大后步长 `38/√zoom` 缩小，越近看细笔越密，把被拉大的斜划之间的缝填上。
- **笔型四变**：横向燥笔 / 斜撇 / 双勾叶形 / 三笔散点短簇，各自长度角度独立。
- **双勾只作点睛**：约两成，且只在簇心；其余写意。第一版曾按 21px 网格撒 2623 笔同款弧、七成带勾，实拍直接变成纹样平铺，已推翻。

实测笔数：×1.64 → 187，×2.70 → 351，×3.46 → 426。

## 「不要太一样」的落点

1. **南北异风**：底罩由连续场生成，秦岭—淮河过渡带宽 8°，笔型按场权重概率混合交错，不出现硬切线。北方横向燥笔束（战后荒田，短断稀）；南方田埂只在低频高值区成簇、随风向倾斜、时有缺笔；岭南疏笔；沙碛与塞北极稀短弧。
2. **不等距扫描**：行距连续变化，笔向叠局部噪声，避免整齐斜纹阵列。
3. **密度连续**：`density` 由低频场 + 区域衰减给出，中原与江南密、河西/辽东/日南疏；底罩 alpha 随密度变化，纸从边地连续透出，留一丢丢白。
4. **长城三重**：阴山主墙 + 河套外长城双线 + 河西沿弱水至居延 + 辽东段；烽燧不等距、大小不一、只在主墙与外线出现、部分带积薪。

## 放大工笔层：树种连续场（F）

挂最久的一条观感账是「放大后叶团仍是一簇簇可辨小团」。根因是 `drawInkDetail()` 的笔型 `Math.floor(rnd*4)` **随机四选一**，与地理无关；颜色还是一串 `if` 切出来的离散档。本轮两处都换成连续场：

- `canopy` 由 `density / south / wet / desert / lingnan / coast / sand / karst` 连续给出 → `needle`（细长收尖）/ `broad`（短粗成簇）/ `shrub`（横走扁平）三套笔的**连续权重**，过渡带里三套交错，不硬切。
- 笔长、笔宽、扇形、双勾概率全由 `canopy` 与簇场调制；色阶改成锚点间线性插值 + 小幅噪声，没有色片台阶。
- **只改放大才显的屏幕空间层**：`a=clamp((zoom-1.45)/1.05,0,1)`，×1 时直接 return，全境默认态一个像素不变。`src/atlas.js` 与 demos 两份内核同步。

实拍 ×4.20 工笔 595 笔（此前 ×3.46 为 426 笔），笔型由场决定而非随机。

## 第五轮：框选反馈与矢量底罩定稿

**框选圈此前是看不见的。** `lostpointercapture` 在 `mouseup` 后照常触发，旧代码把
它和 `pointercancel` 绑到同一个处理器，刚落下的 `circle` 被立刻清成 `null`——
玩家画完圈得不到任何反馈。拆成两个监听后圈正常存活 800ms。顺带把 `ctx.arc`
标准正圆 + `[5,4]` 虚线阵列换成 `inkRing()`：26 点低频形变的一圈不规则运笔，
收笔留两小段缺口，不是圆也不是虚线；拖单兵落点同改。**选人逻辑未动**，框选仍
一次选中 9 兵。这正对上墨战「决策和部署能够及时反馈、框选无延迟」那条 [28]。

**矢量底罩的块感也消了。** 五组纯底罩实测（相邻行阶跃 >1 的像素）：
`100×78 + blur2.6 = 8578`；`140×110 + blur 2.6 / 4.0 / 6.0 / 8.0 =
6928 / 2872 / 2479 / 1992`。定稿 **140×110 色块 + `stdDeviation=8.0`**，
南北低频渐变仍完整，文件 2.0MB → 3.0MB。中间试过「只细化色块不改模糊」
与「回退到旧参数」，都被实测否掉了；也试过把对照文件放到服务根之外，
得到过一次 404 假数据，已剔除，不写进结论。

当前 `demos/atlas-vector.svg` 与 `demos/建安五年全境舆图-全量矢量.svg` 均为
**6144 path / 15401 rect / 无 `<image>`**，标题「全量矢量」。

### 自动避让（四层）

原来 `drawLabels` 是「包围盒相交就 `continue`」，一撞就把整个注记删掉。放大档
L3 有 80 县邑 + 40 郡治 + 墨注，密处被整片吃空，反而比不避让更稀，剩下的还
容易糊在一起。改成：

1. **十三方向候选位**（原位 / 八邻 / 两档距离），撞了先挪，不是一删了之
2. **朱题、州治是锚，绝不挪**；只有郡治 / 墨注 / 县邑让位
3. 十三方向都放不下时，低优先级**微缩到 0.82 字号**再试一轮，仍不行才跳过
4. 包围盒外扩**呼吸空间** `2.0*k + 0.45*字号`：只判硬贴边的话，字虽不重叠仍
   会挨成一片糊；朱题带不规则淡纸衬，包围盒按实际外扩，别让别的字压上去

实拍 demos ×2.10 进 L3（状态栏「注记 L3 县邑 · 工笔 237 笔」），中原核心区
仍是一片淡小字，但已能分出单个地名，**没有字面重叠**。密处少显是既定的 LOD
口径，没有为了「看起来清爽」硬删县名。

### 竖屏：上轮那句话没讲清楚，这里用大白话重讲

上轮我说「典籍页画布变高后首屏要滚一下才见岭南」——那是**桌面横屏**的情况：
画布从 558px 高变成 1036px，一屏只有约 740px 能看，所以一进页面只看到北半张，
要看南边得往下滚。我想说「南边画了，只是被屏幕挡住，不是没画完」。

但你是**手机竖屏**，完全不是这回事。竖屏下按 1.27:1 的横图比例，390px 宽只会
得到 **344×270** 的一小块画布，整幅十三州缩成一团、地名挤在一起（已实拍）。
我拿桌面情况在讲，对不上你的场景，难怪看不懂。

竖屏这么调：

| | 之前 | 现在 |
|---|---|---|
| 画布 | 344×270（按横图比例压成矮条） | 344×591（`min(70vh,600px)`） |
| 地图 | 挤成一小块 | 按宽度铺满，上下留暗绢渐变（不是死黑），读成摊开的卷轴 |
| 一进来 | ×1.00 全境，字挤 | **×1.55**，字和地名散得开、能读，左右拖着看 |
| 「复位」 | — | 回 ×1.00 整幅全境（想看全貌时挤一点是预期） |

页面说明里也直接写了一句「竖屏一进来是放大到能读的局部，左右拖着看；点『复位』
回到整幅十三州全境」，不再让玩家猜。桌面横屏一个像素没动。

### 顺带修的真 bug：分图按钮第一次点了没反应

验证时发现「中原详图」第一次点击文本不变、画面不切，第二次才生效。查下来是
`refreshUI()` 里 `if (shell?.depth > 0) shell.render()` 会重建整块 `innerHTML`，
`mountAtlas()` 随之重跑，把 `zoom / focus / detail` 全部重置回初始值——用户
刚选的档位被一次重建冲掉。两处一起修：

- 视图状态提到实例外的 `atlasState`，`paint()` 每次写回；重建后接着用户已选的
  档位，并重新 `a.setFocus(focus)`、调 `syncFocusButtons()` 对齐按钮文本/aria
- 「中原详图」入口改成按当前档显式切（`focus === 'zhongyuan' ? 'all' : 'zhongyuan'`），
  不再靠 `detail` 布尔量推断，避免它与 `focus` 不同步

实拍：**第一次点击即生效**（差异 870423 像素、按钮变「返回全境」）；强制
`refreshUI()` 重建后与点击后**逐像素一致（差异 0）**；河北详图 aria true、
复位回全境，四档缩放全程零报错。

预览：`preview-avoid-l3.png`（典籍页中原 L3 避让定稿）、`preview-atlas-portrait.png`
（竖屏 ×1.55）、`preview-atlas-portrait-reset.png`（竖屏复位全境）。

## 第十轮：上轮的「自动避让」只改了一半，这轮补到玩家天天看的主地图

### 先认一句更重的

上轮我写了「撤掉『古舆图本有叠压，没做自动避让』」并交了差，但**只改了典籍页
`atlas.js` 的 `drawLabels`**。实拍默认主地图 ×2.4 才发现：默认 `style` 是
`atlas`，而 `map-render.js` 里 `if (style !== 'atlas') drawAnnotations(ctx)` ——
**玩家天天看的那张图，注记根本不走我改的那个函数**。城名、关津、题识全烘焙在
`guandu.js` 生成的位图里，等级角标是运行时叠上去的，于是满屏 5/6/7 与
「陈留」「浚仪」「乌巢」糊成一片。用户点名的正是这一处，我却去修了另一页。

### 补法：避让下沉到生成期，仪表让位于字

| 层 | 改动 |
|---|---|
| `guandu.js` `vertical()` | 位图注记统一做生成期四层避让（撞了先挪 → 题识大字不挪 → 小字微缩 0.82 → 兜底回原位）；**绝不跳过**，因为很多注记是「先描边、再填色」两遍配对，跳过只剩空心字 |
| 描边配对 | 原来调用方在固定坐标 `strokeText`，`vertical` 挪位后填色，实拍出现**空心描边 + 实心字错位鬼影**。改为 `vertical` 自带 `halo` 参数，描边与填色同一次布局画完；题识、城名、`sceneLabel` 五处主景全部改单次调用 |
| 注记盒导出 | `renderGuanduLayers` 返回 `nameBoxes`（guandu 逻辑坐标）+ `cropLogical`，共 77 处注记 |
| `map-render.js` | `buildAtlasBase` 把盒按 `drawImage` 同一变换映射成主地图世界坐标 `bakedBoxes`；`buildBase` 切档清空 |
| `drawLevels` | 等级角标从每格都画 → **四格取一**，且落在运行时注记盒或位图注记盒内直接跳过；角标宽度按 `9/camera.scale` 换算成世界单位，不再拿屏幕像素当世界坐标 |
| `drawAnnotations` | 运行时档（gongbi / jiehua / quanjing）也统一入队，四层避让，都城 / 郡治是锚不挪；避让后的盒交给 `drawLevels` |

**兜底一致性**修过一次：第一版十三方向都放不下时盒按最后候选位记、字却画回原位，
盒与画不符。改成 `found` 标志，兜底时把位移 / 字号全部复位再记盒。

**口径残留**：README 第 209 行那句更早的「作战区五处主景注记……左侧仍略密；
古舆图本有叠压，未做自动避让」也一并撤除，五处主景现在走同一套避让。

### 实拍

- ×2.4 中原：改动前满屏 5/6/7 与城名糊成一片；改后数字四格取一且避开 77 个
  注记盒，「陈留」「浚仪」「乌巢」能分出单个字，无空心鬼影
- ×1 默认态：差异 15068 像素，全是位图注记让位与描边配对，观感未被破坏
- 四档 `atlas / gongbi / jiehua / quanjing` 在 ×2.0 显式重绘逐帧零报错

  `if (style !== 'atlas') drawAnnotations(ctx)`）导致的红，用**恢复精确写法**
  消掉：注记盒改模块级变量传递，不动断言，避免与并行提交抢同一文件
