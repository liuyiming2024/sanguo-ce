## 打开

浏览器直接打开 `建安五年全境舆图.html`（自包含，无外部依赖、无位图）。

- 滚轮缩放 / 拖动平移
- 「重落一笔」换 seed 重画
- 「地物层」切地物显隐
- 「压上格子」默认压上，缩小按 LOD 退场
- 「放大 / 缩小 / 复位」

## 「不要太一样」的落点

1. **南北异风**：底罩由连续场生成，秦岭—淮河过渡带宽 8°，笔型按场权重**概率混合**交错，不出现硬切线。北方横向燥笔束（战后荒田，短断稀）；南方田块只在低频高值区成簇、随风向倾斜、时有缺笔；岭南疏点；沙碛与塞北极稀短弧。
2. **密度连续**：`density` 由低频场 + 区域衰减给出，中原与江南密、河西/辽东/日南疏；底罩 alpha 随密度变化，纸从边地连续透出，留一丢丢白。
3. **势态不是实心色块**：曹、袁、孙、刘表、刘璋、马韩、士燮、公孙度、张鲁、黑山、乌桓、鲜卑、羌、山越各为渗透渐变团；汝南为朱白相间渗透带（建安五年刘备、刘辟响应袁绍，建安六年复起）。
4. **长城三重**：阴山主墙 + 河套外长城双线 + 河西沿弱水至居延 + 辽东段；烽燧不等距、大小不一、部分带积薪。
5. **州治 / 郡治分级**，官渡核心区保留东西连营两道长壕、沙堆、乌巢粮囤、屯田沟洫，放大可见。

## 已知局限

- 叶团仍是可辨小簇，双勾轮廓与留水线尚未实现；放大后仍有点彩感。
- 黄河中段线条偏亮，双勾岸线在全境尺度下简化为单线。
- 郡治点位为近似今地；105 郡国级地名未全量核异说。
- 边地（河西、辽东、日南、乐浪）史料密度低，留白大是有意的。
- 放大后官渡核心区与周边州名仍有局部叠压，未做自动避让。
