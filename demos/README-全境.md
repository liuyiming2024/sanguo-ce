## 打开

浏览器直接打开 `建安五年全境舆图.html`（自包含，无外部依赖、无位图）。

- 滚轮缩放 / 拖动平移
- 「重落一笔」换 seed 重画
- 「地物层」切地物显隐
- 「压上格子」默认压上，缩小按 LOD 退场
- 「放大 / 缩小 / 复位」

## 图幅

`93~126°E / 15~43°N`。此前口述的 `100~124°E / 21~42°N` 不成立：敦煌约 94.7°E、玉门关约 93.9°E、乐浪约 125.8°E、日南象林约 16°N 均在框外。西止玉门关（西域诸国不画）、东含乐浪、南含日南、北含河套外长城。海南不画（珠崖已罢）。近似等距圆柱投影，题识注明「纵横不拘实距」。

## 三条硬约束（本轮按反馈调整）

**① 势力层整层删除。** 归属与玩家局内动态相关，**由上层逻辑负责**，背景层只给地与物。`POWERS` 径向渐变团、汝南朱白渗透带、势力名一律不画。州界朱线是行政区划示意，不是势力，保留但碎化成断续界标笔。

**② 去几何图元。** 全图不再有 `ellipse` / `strokeRect` / `fillRect` 画出的地物：

| 原几何 | 改为 |
|---|---|
| 泽的椭圆、沙洲椭圆 | `irregular()` 不规则闭合笔路（半径由低频噪声连续给出，一次运笔） |
| 州治／郡治方块 | 不规则墨点 + 州治竖排名／郡治横注 |
| 营垒方框 | 不规则营圈，大小不一、不等距 |
| 乌巢方粮仓 | 圆形粮**囷**（汉代囷为圆，非方屋）+ 晒场笔 |
| 南方田块四边形 | 只留断续田埂短笔，不闭合 |
| 烽燧白方块 | `sealBox()` 手刻缺损坞垣 + 不规则角楼 |
| 图廓双矩形 | 抖笔折线 |
| 比例尺贯通直线 | 断续短笔刻度 |
| 朱印纯 rect | 手刻缺损印形（汉印本方，取刻石感） |
| 州界闭合多边形 | 沿折线按弧长抖点、首尾不闭合的界标笔 |

**③ 有个性 + 明重点。** 补 13 处史料点名、俯视有辨识度的主景，每处**单独写绘制代码**，不是同一图章循环：

| 级别 | 景物 |
|---|---|
| **一级朱题（3）** | 官渡连营（含土山高橹、霹雳车、地道—长堑、沙堆）、雒阳灵台、居延积薪 |
| 二级墨注（10） | 邙山东汉圆丘封土与冢柏、阳城汉三阙、轘辕关十二曲、圃田泽二十四浦、黄河金堤与十里一水门、枣祗河／任峻「铜底铁帮运粮河」、白马津浮桥、乌巢粮囷、蜀郡临邛火井、会稽鉴湖 |

重点靠**朱色 + 竖排 + 15px 字级 + 不规则淡纸衬**点明，不靠画框；其余只给 10px 墨注，有个性但不抢。题识第三行只列三个朱题，余景见墨注。

**临邛火井**：汉代蜀郡临邛已见火井（天然气井）记载，画井口 + 井架 + 一点幽火；**会稽鉴湖**：东汉顺帝永和五年（140）会稽太守马臻筑，画不规则湖 + 断续堤塘 + 斗门。两处补在南方，解决「南方只有普通短划」的空。

## 「不要太一样」的落点

1. **南北异风**：底罩由连续场生成，秦岭—淮河过渡带宽 8°，笔型按场权重**概率混合**交错，不出现硬切线。北方横向燥笔束（战后荒田，短断稀）；南方田埂只在低频高值区成簇、随风向倾斜、时有缺笔；岭南疏点；沙碛与塞北极稀短弧。
2. **不等距扫描**：行距 `9+rnd()*8` 连续变化，笔向加局部噪声，避免整齐斜纹阵列。
3. **密度连续**：`density` 由低频场 + 区域衰减给出，中原与江南密、河西/辽东/日南疏；底罩 alpha 随密度变化，纸从边地连续透出，留一丢丢白。
4. **长城三重**：阴山主墙 + 河套外长城双线 + 河西沿弱水至居延 + 辽东段；烽燧不等距、大小不一、只在主墙与外线出现、部分带积薪。
5. 州治／郡治分级、官渡核心区战具，放大可见。

## 已知局限

- 中原在全境尺度下只有约 150×100 px，13 州治 + 40 郡治 + 8 个二级墨注必然局部叠压；三个朱题靠淡纸衬跳出，但小字仍有挤。若要彻底解决需另出一幅「中原详图」。
- 州界碎化后极淡，几乎只剩界标感；要读行政区划需放大。
- 叶团仍是可辨小簇，双勾轮廓与留水线尚未实现。
- 黄河在全境尺度下简化为单线双勾，中段偏亮。
- 郡治点位为近似今地；105 郡国级地名未全量核异说。
- 边地（河西、辽东、日南、乐浪）史料密度低，留白大是有意的。
