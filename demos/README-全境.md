# demos · 建安五年十三州全境舆图

单文件实验，**不接入 `src/`**，不修改 `terrain.js` / `map-data.js` / 存档 / 策略层；主 README、`package.json`、`index.html` 的 `?v=` 一律未动，**大版本号保持 0**。

## 打开

浏览器直接打开 `建安五年全境舆图.html`（自包含，无外部依赖、无位图）。

- 滚轮缩放 / 拖动平移
- 「重落一笔」换 seed 重画
- 「地物层」切地物显隐
- 「工笔」切屏幕空间双勾细笔层（放大时渐显）
- 「压上格子」默认压上，缩小按 LOD 退场
- 「中原详图 / 返回全境」一键切到官渡—许都一线的大局部（×2.70）
- 「放大 / 缩小 / 复位」

`93~126°E / 15~43°N`。此前口述的 `100~124°E / 21~42°N` 不成立：敦煌约 94.7°E、玉门关约 93.9°E、乐浪约 125.8°E、日南象林约 16°N 均在框外。西止玉门关（西域诸国不画）、东含乐浪、南含日南、北含河套外长城。海南不画（珠崖已罢）。近似等距圆柱投影，题识注明「纵横不拘实距」。

## 势力层不画

归属与玩家局内动态相关，**由上层逻辑负责**。背景层只给地与物：`POWERS` 径向渐变团、汝南朱白渗透带、势力名一律不画。州界朱线是行政区划示意，不是势力，碎化成断续界标笔。史料取数表里的势力章节保留为备查，不作绘制依据。

## 三层 LOD（格网 / 注记 / 背景笔）

| 层 | 低倍率 | 高倍率 | 关键 |
|---|---|---|---|
| **格网** | ×0.29 全隐 → ×0.61 主格 → ×1 全显 | 线宽按 `1/z` 补偿，恒定粗细 | 缩小防密 |
| **注记** | L1 州治 + 3 朱题 | L2 郡治/州界/墨注 → L3 汉末县邑 | 屏幕固定字号，不随缩放糊掉 |
| **背景笔** | 离屏 1× 渲染 | 跨档重渲（×2/×3），笔在逻辑坐标里缩小加密 | 放大不把笔拉成鱼鳞 |

**注记分级**：文字不烘进离屏图层，按屏幕固定字号绘制，只按倍率做 `0.90~1.18` 微调和档位切换。

| 档 | 触发 | 显示内容 |
|---|---|---|
| **L1** | 全境 ×1 及以下 | 13 州治 + 3 处一级朱题 |
| **L2** | `zoom≥1.15`（详图下 `≥0.85`） | + 郡治、州界名、10 处二级墨注 |
| **L3** | `zoom≥2.00`（详图下 `≥1.30`） | + 约 80 个汉末县邑 |

- **碰撞避让**：按 `朱题 > 州治 > 州界 > 郡治/墨注 > 县邑` 依次落字，包围盒相交的下级自动跳过。密处少显、疏处多显。
- 详图模式放宽阈值但**不锁死**：继续缩小，注记照样逐层收起（实测 ×2.70 → ×1.01 由 L3 退回 L2）。
- 详图时图廓题识被移出视口，补屏幕固定题签「中原详图 · 官渡至许都」。

**背景按倍率重渲**是本轮最关键的一处。此前背景是固定 1400×1100 的离屏 canvas，×2.7 放大只是把像素拉大，短笔被拉成整齐的鱼鳞斜纹——那正是「平铺感」在大局部下的复发。现在 `makeBg(zb)` 在跨档时重算：笔触在逻辑坐标里按 `k=1/zb` 缩小加密，离屏图超采样 `S=ceil(zb)` 倍保证清晰，合成后屏幕笔宽 ≈ 原尺寸。滚轮/拖动仍只做即时合成，重渲只在倍率跨整数档时发生。

**三级县邑**为《续汉书·郡国志》司隶河南尹/河内、兖州陈留/东郡、豫州颍川/汝南/梁/沛/陈、冀州魏郡的真实县名（中牟、阳武、酸枣、浚仪、雍丘、长社、召陵、苦、下邑、鄄城、馆陶、野王、荥阳、故市……），今地坐标为示意近似值，接回 `src/` 前须逐条核坐标。

## 工笔层：双勾 + 水线

`brush()` 增加 `hook`：沿笔的左右缘各描一线，内缘留一道纸白「水线」。**不是给笔加框**——缘是笔自己的边界，随提按收尖，那道白是染与线之间的留隙。

屏幕空间另起一层 `drawInkDetail()`，反算地理坐标决定笔型、方向、疏密（笔跟着地走，不跟屏幕漂），`zoom≥1.45` 渐显：

- **成簇不铺满**：低频簇场 `fbm<.535` 整片跳过，簇心概率落笔；放大后步长 `38/√zoom` 缩小，越近看细笔越密，把被拉大的斜划之间的缝填上。
- **笔型四变**：横向燥笔 / 斜撇 / 双勾叶形 / 三笔散点短簇，各自长度角度独立。
- **双勾只作点睛**：约两成，且只在簇心；其余写意。第一版曾按 21px 网格撒 2623 笔同款弧、七成带勾，实拍直接变成纹样平铺，已推翻。

实测笔数：×1.64 → 187，×2.70 → 351，×3.46 → 426。

## 「不要太一样」的落点

1. **南北异风**：底罩由连续场生成，秦岭—淮河过渡带宽 8°，笔型按场权重概率混合交错，不出现硬切线。北方横向燥笔束（战后荒田，短断稀）；南方田埂只在低频高值区成簇、随风向倾斜、时有缺笔；岭南疏笔；沙碛与塞北极稀短弧。
2. **不等距扫描**：行距连续变化，笔向叠局部噪声，避免整齐斜纹阵列。
3. **密度连续**：`density` 由低频场 + 区域衰减给出，中原与江南密、河西/辽东/日南疏；底罩 alpha 随密度变化，纸从边地连续透出，留一丢丢白。
4. **长城三重**：阴山主墙 + 河套外长城双线 + 河西沿弱水至居延 + 辽东段；烽燧不等距、大小不一、只在主墙与外线出现、部分带积薪。

## 已知局限

- 州界碎化后极淡，几乎只剩界标感；要读行政区划需放大。
- 黄河在全境尺度下仍是单线双勾（比早期版本已压暗）；支流水纹靠断续短笔，不作双勾河岸的写实复原。
- 郡治 / 80 个县邑的今地经纬度为示意近似值；105 郡国级地名未全量核异说。接回 `src/` 前须逐条核坐标并跑 `validateMap()`。
- 边地（河西、辽东、日南、乐浪）史料密度低，留白大是有意的。
- 极高倍率（×4 以上）工笔层与背景笔叠加会略密，但笔型四变 + 簇场抽稀，不会退回均匀纹样。
