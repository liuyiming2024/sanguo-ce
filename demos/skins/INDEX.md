# 六档风格索引 · 看完再选一个

> 用户：「多开几次，到时候我再选一个风格。」
> 于是从第十七轮的两档扩到 **A–F 六档**，每档都是一份参数、共用同一套史料
> 锚点与注记避让，工具条可即时切换，导出 SVG 的 `<desc>` / `<metadata>`
> 写明皮肤名。**默认仍是 A 写意底图（现行基线）**，没有把任何候选设为定稿。

## 一眼对照

| 档 | 名称 | 底色 | 笔色 | 山势 | 格网 | 想解决什么 |
|---|---|---|---|---|---|---|
| **A** | 写意底图（现行） | 暖纸→青绿渐变 | 原色 | 无 | 关 | 回退基线，什么都不改 |
| **B** | 形象画法 | 淡纸 | 原色 | 披麻皴 | 关 | 让它像一张淡墨画 |
| **C** | 旧绢设色 | 赭黄旧绢 | 暖化 + 矿物色 | 没骨宽笔 | 关 | 让它像一幅古绢本设色舆图 |
| **D** | 水墨素卷 | 近白纸 | **全图灰阶** | 浓墨立骨 | 关 | 只靠浓淡分层，朱题唯一彩 |
| **E** | 计里画方 | 冷纸 | 冷调 | 无 | **细朱方格** | 走《广舆图》规整制图一路 |
| **F** | 夜墨暗绢 | 深墨 | **暗笔提亮** | 浅笔立骨 | 关 | 与主工程墨底 UI 统一气质 |

实拍总览：`/data/workspace/shots_skin6/0-六风格总览.png`（六宫格）；
每档 1440×1000 单图在同目录 `1-A` … `6-F`。
每档静态矢量在本目录 `风格A-写意底图.svg` … `风格F-夜墨暗绢.svg`，
**全是新名字**，不会和你手上那份平台旧「矢量骨架」快照混淆。

## 各自的取舍（挑的时候看这段）

- **A 与 C 同属暖调**，C 更黄、有没骨山；若嫌两者太像，优先在 C 的
  `silk` 底罩上继续加重赭色，而不是改 A（A 是回退锚点，别动）。
- **B 与 D 都是纸主导**，B 淡墨披麻、D 纯墨立骨；D 的山更明显但秦岭一段
  略带锯齿感，B 更含蓄。
- **E 会读成坐标纸**——这是「计里画方」这一路本身的形态，不是 bug。
  你最早点名过「格网像坐标纸」，所以它只作为**备选项**存在，默认关闭。
- **F 辨识度最高，但偏暗、小字弱**。第一版把每支淡墨都反白，实拍满图
  浅短划、城邑成白贴纸、朱印成亮橙方块；已压暗一次，仍可能需要再提亮。

## 六档共有的、皮肤解决不了的边界

**上半有内容、下半一大片空。** 六档都一样——换底色、换笔色、换山势都
补不出南方的东西，因为郡县与主景本来就集中在北方，交州／日南只剩几个
地名。这是史料密度 + 图幅取 `15~43°N` 全境共同决定的构图结果。
要根治得另做一轮「南方主景补足」或把默认图幅改成中原核心区，
**那不是换皮肤能解决的**，所以本轮没偷偷补假景物。

其余：城郭与注记层级六档一律没动（变量少才好归因）；势力层仍不画；
六条主脊与黄河都用仓库既有 `RIDGES` / `HUANGHE` 常量，没有新造地名与坐标。

## 怎么选 / 怎么回退

工具条最左「皮肤」下拉即时切换；「导出矢量」按当前皮肤出图，文件名带
皮肤短名。`classic` 导出的 `<g id="strokes">` 与备份基线 SVG **逐字相同**，
切到任意档再切回仍逐字相同——这是回退硬证据。

备份与三选一回退方式见 `BACKUP.md`；选完给一句「留 X」即可，我再把它
接进 `src/atlas.js` / 典籍页 / 主地图，参数不用重画，直接读同一份 JSON。
