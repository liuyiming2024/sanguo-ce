## 本轮审美：从「色片平铺」到「笔」

上一轮放大到 ×3 后，画面读成一片**一个个可辨的小色片**——点彩感。两个根因：

1. 色板是一串 `if` 把场值切成 7 档、每档两个随机色，放大就是边界清晰的同色块；
2. 每个树冠团是一个闭合五边形，本身就是小色片，不是笔。

这轮换掉生成语法，不靠加噪点或调色：

| 原来 | 现在 |
| --- | --- |
| 7 档离散色片 | `CANOPY` 锚点间**线性插值**的连续色阶，湿度/受光/树种只做连续小幅偏移，色相没有台阶 |
| 闭合五边形 | `brush()` **变宽短笔**：根部聚一点、起粗收尖的一次运笔，一簇合成一条 path 一次 fill |
| 团内方向各自随机 | `windAt()` 由连续场梯度给主风势 + 扇形展开；加中频项让相邻区域笔势连续渐变 |
| 三套笔型分档切换 | 针叶（细长收尖）/ 阔叶（短粗成簇）/ 灌丛（横走扁平）按场值**连续混合** |
| 浅田也画浅色树冠 | `fieldTuft()`：低场改用**成组平行田埂细笔**，行向由连续角场给、带中频换向；与林冠是两套视觉语法 |
| 全域一个密度 | 密度随场值走：深林几乎不留缝，浅田笔组之间露出淡赭底罩 |

低场/高场用**概率连续混合**（`fieldness = 1 - smooth(.22,.40,e)`）分流，不做硬阈值，
过渡带是散的，不会出现一条分界线。

**工笔第一道工序也补上了**：`fieldWash()` 把场图写成 `FW×FH` 的 ImageData 再放大绘制，
得到一层完全连续、无台阶无重复单元的底罩。笔改细之后必然留缝，白底会从缝里大面积
回来（实测露纸一度冲到 **45%**）；先罩底色、再叠笔，白只从场值低的地方连续地漏一丢丢。
这正是"先罩底色、再叠笔"的工序，也是用户说的「可以铺一点点类似地形的背景，但不要全铺」。

配色上一并拉开冷暖：低场赭黄、深林墨青、湿林花青，河岸泽缘有一圈青灰湿林带。

| 状态 | 露纸 | 近纯白 |
| --- | --- | --- |
| 纯背景 | **7.6%** | 0.14% |
| 完整图 | **8.2%** | 0.37% |

城郭另加一层**柔边托光**（工笔的「托底」）：中部官渡/中牟/陈留几座城叠得近，
细线在密笔背景上容易糊；渐隐的纸光让城浮出来，边缘是软的，不是实心圆饼的贴纸感。

## 格网 LOD：缩小到一定程度自动隐去

格子是**上层**，与地图本体同处一个 canvas 变换，所以是「压上去」的。判据用
`view.zoom` 而非绝对屏幕像素：`K` 随视口宽变，窄屏默认视图的格子本来就比桌面密，
用绝对 px 会让手机一打开就看不到格子。

| zoom | 细格（每格） | 主格（每 5 格） | 状态 |
| --- | --- | --- | --- |
| ≥ .90 | 全显 | 全显 | 全显 |
| .69 ~ .90 | 渐隐 | 全显 | 细格渐隐（抽稀） |
| .36 ~ .69 | 已无 | 渐隐 | 仅主格渐隐 |
| < .36 | 无 | 无 | **已隐去（防密）** |

`smoothstep` 连续过渡，不做硬开关；线宽按 `1/(K*zoom)` 补偿保持恒定屏幕粗细；
墨底 + 亮金双色保证深浅底都可读；同色同批格线合成一条 path 一次 stroke。

「防止太密」主要靠**抽稀**而非最后的隐藏：细格从 ×0.90 就开始淡出，×0.64 只剩
每 5 格一条主格，这时候已经不糊了；×0.36 以下才彻底隐去。

实拍验证（格网开/关的中央 600×400 像素差）：`×1.00` 8920 → `×0.32` **0** → `×3.40` 4523。

## 性能：离屏分层缓存

背景层与地物层各渲一次到两张 2400×1760（SS=2）离屏 canvas，**与 zoom 无关**。
缩放/平移/切层只做 `drawImage` 合成 + 实时画格网，不重画上万个树冠团。

- 只有「重落一笔」换 `baseSeed` 才重建；重建前 `seed = baseSeed` 保证幂等。
- `requestAnimationFrame` 合并连续滚轮/拖动事件；`resize` 只重新合成。
- 本轮首渲染约 **3.4s**（加了 `fieldWash` 与更多短笔），仍只在重建时付一次；
  切地物层约 127ms，无 console / pageerror。

## 题识与比例尺画在 canvas 里

原本是 HTML 叠层，缩到 ×0.32 时会停在左上角/右下角、悬在图外纸面上。改成
`inscriptions()` 画在背景层内，随地图一起变换。缩放时画布四周露出的也改成比纸深一档的
绢帛色 `#c5bda6` + 径向暗角，读成「摊在案上的卷轴」，不是「地图没画完的白洞」。

## 视角：空中俯瞰，只看见树，看不见山

画面里没有「山」这个物件：从上看下去只有连续郁闭的林冠，山的走向只能由林冠明暗起伏、
树种深浅、沟谷里更暗的林带**被读出来**。`ridge()` 整个山形绘制、远山剪影、
折带/斧劈皴、山脚坡带都已删除；四条 `RIDGES` 只是**地形场的隆起轴**
（嵩箕林 / 箕山坞 / 太行林 / 历山坞）。

## 连续地形场，不是格网

`buildField()` 预采样 241×177 场图（`FIELD / WET / OPEN`），双线性插值查询：

```
E = Σ 脊轴高斯隆起 − 河谷/泽薮下切 + 三层低频连续起伏 − 城外清场
W = 到最近水系的湿度
O = 城外浅田环 / 沙洲 / 图廓内侧的「留白意愿」
```

场图只是**连续函数的采样缓存**，不参与绘制决策的重复单元。所有笔触位置由
「带 carry 的不等距扫描游走」给出，不遍历场图格子，也没有任何可复制的图章函数。

城外清场半径刻意收窄（`c.r*.48`）——上一版几座城叠起来在中部连成一大片纯纸白，
读成「挖了个洞」而不是「城外开阔地」。

## 绘制顺序

```
背景层：纸 → 图廓 → 建场 → 连续场薄罩 → 林冠/田畴笔 → 泽/河 → 湿林带 → 题识
地物层：桥舟 → 聚落田畴 → 城 → 关津        （可关）
上层  ：格网（LOD）                        （默认开，可关）
```

> 已修真 bug：`wetBands()` 原塞在 `surfaceCover()` 里，而它依赖的 `RIVER_GEO`
> 由 `river()` 填充，调用顺序在前，整个循环空转、河两岸是秃的。

## 层次拆分

| 层 | 内容 |
| --- | --- |
| **背景层** | 纸、廓、连续场、薄罩、林冠、田畴、灌丛、水、湿林带、题识 |
| **地物层** | 十二城郭、关津、桥舟、城外聚落田畴、烽燧 |
| **上层** | 格网；真接进主地图后还有势力色、部队、路线 |

背景层**不放任何居民点或点景建筑**。地物层的密由真实锚点派生：每处聚落挂在某座城或
关津上，朝向取最近河段切线角，`inDeepCanopy()` 用连续场避开郁闭深林。
城与城之间**不画任何路线**。

## 已知局限

1. 仍是「工笔化的舆图」而非严格工笔：短硬笔与连续薄罩做了，没做十八描线型分类，
   也没做矿物/植物颜料的物理扩散与分区平涂逐层罩。
2. 放大到 ×3 以上仍能辨出一簇簇叶团，但那已是**笔**而非色片；若要更贴工笔，
   下一步是让叶团带双勾轮廓与留水线，而不是继续加密。
3. 田畴笔虽加了中频换向，局部仍能看出成组平行线；靠城郭托光与地名打散。
4. 城外聚落仍是同规格小屋，可按城的性质（军屯 / 市邑 / 驿）换结构。
5. 支流两岸湿林带略像一条斜向划线，靠水名与水面区分。
6. 形象画法允许超比例压缩，投影不等比，题识已注明「纵横不拘实距」。
7. **LOD 阈值是演示值**：接进主地图时 `zoom` 应换成相机实际倍率，`.36/.69/.90`
   按真机像素密度再标一次；这段是纯函数，可直接搬到渲染层，不依赖存档。

## 与 v0.6.0 的关系

README 记录的「一笔山脊实验」结论要求「笔要读成受光的脊而不是沟，两侧皴法得顺着笔势
组织」。本实验不叠在任何格状层之上，且进一步取消了「脊」这个可见物件。
**这是对照样本，不是结论** —— 是否替换 `buildBase()` 的静态层，仍需按仓库烟测口径
做 A/B。配色清单（v0.5.0 收尾）仍未落地，`styles/main.css` 保持原样。
