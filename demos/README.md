## 格网 LOD：缩小到一定程度自动隐去

格子是**上层**，与地图本体同处一个 canvas 变换，所以是「压上去」的，不是另贴一层。
判据用 `view.zoom` 而非绝对屏幕像素：`K` 随视口宽变，窄屏默认视图的格子本来就比
桌面密，用绝对 px 会让手机一打开就看不到格子。zoom 是相对整幅图的倍率，任何视口下
「缩到 0.36 倍以下就太密」都成立。

| zoom | 细格（每格） | 主格（每 5 格） | 状态 |
| --- | --- | --- | --- |
| ≥ .90 | 全显 | 全显 | 全显 |
| .69 ~ .90 | 渐隐 | 全显 | 细格渐隐（抽稀） |
| .36 ~ .69 | 已无 | 渐隐 | 仅主格渐隐 |
| < .36 | 无 | 无 | **已隐去（防密）** |

- 用 `smoothstep` 连续过渡，不做硬开关，缩放时不会突然跳没。
- 线宽按 `1/(K*zoom)` 补偿，缩放时保持恒定屏幕粗细，不跟着地图变粗变细。
- 双色描边：墨底线压在浅田上看得见，亮金线压在深林上看得见。
- 同色同批格线合成一条 path 一次 stroke，成本可忽略。

「防止太密」主要靠**抽稀**而非最后的隐藏：细格从 ×0.90 就开始淡出，到 ×0.64 只剩
每 5 格一条主格（屏幕间距 210px 级），这时候已经完全不密了；×0.36 以下才彻底隐去。

**实拍验证**（对比格网开/关的中央 600×400 像素差）：

| 状态 | 格线像素差 |
| --- | --- |
| ×1.00 全显 | 8920 |
| ×0.32 已隐去 | **0** |
| ×3.40 全显 | 4523 |

## 性能：离屏分层缓存

背景层与地物层各渲一次到两张 2400×1760（SS=2）离屏 canvas，**与 zoom 无关**。
缩放/平移/切层只做 `drawImage` 合成 + 实时画格网，不再重画上万个树冠团。

- 只有「重落一笔」换 `baseSeed` 才重建；重建前 `seed = baseSeed` 保证幂等。
- `requestAnimationFrame` 合并连续滚轮/拖动事件。
- 实测连续 12 次缩小 728ms（含 12 次点击开销）、切地物层 125ms、无 console / pageerror。
- `resize` 只重新合成，不重建离屏层。

## 题识与比例尺画在 canvas 里

原本是 HTML 叠层，缩到 ×0.32 时题识停在左上角、比例尺停在右下角，**悬在图外的纸面上**，
非常出戏。改成 `inscriptions()` 画在背景层内，随地图一起变换。缩放时画布四周露出的
也改成比纸深一档的绢帛色 `#c5bda6` + 径向暗角，读成「摊在案上的卷轴」，而不是
「地图里没画完的白洞」。

## 视角：空中俯瞰，只看见树，看不见山

画面里没有「山」这个物件：从上看下去只有连续郁闭的林冠，山的走向只能由林冠明暗起伏、
树种深浅、沟谷里更暗的林带**被读出来**。`ridge()` 整个山形绘制、远山剪影、
折带/斧劈皴、山脚坡带都已删除；四条 `RIDGES` 只是**地形场的隆起轴**
（嵩箕林 / 箕山坞 / 太行林 / 历山坞）。

## 连续地形场，不是格网

`buildField()` 预采样 241×177 场图（`FIELD / WET / OPEN`），双线性插值查询：

```
E = Σ 脊轴高斯隆起 − 河谷/泽薮下切 + 三层低频连续起伏 − 城外清场
W = 到最近水系的湿度
O = 城外浅田环 / 沙洲 / 图廓内侧的「留白意愿」
```

场图只是**连续函数的采样缓存**，不参与绘制决策的重复单元。所有笔触位置由
「带 carry 的不等距扫描游走」给出，不遍历场图格子，也没有任何可复制的图章函数。

## 面覆盖，不是线簇

第一版让游走带沿等值线跑，带全被梯度吸到高场区聚成条，中间空出大片纸
（露纸率实测 **59%**）。改成**不等距扫描式面覆盖**后：

| 状态 | 露纸 |
| --- | --- |
| 只看背景 | **10.4%** |
| 完整图 | **11.7%** |

白只从**笔缝、泽中沙洲、城外浅田环、图廓内侧**漏出来，是碎的、一丢丢。
上面足够密，眼睛不会往下找底 —— 这是「看不见白底」的意思，不是把纸盖住。

## 绘制顺序

```
背景层：纸 → 图廓 → 建场 → 林冠面覆盖 → 泽/河 → 湿林带 → 题识
地物层：桥舟 → 聚落田畴 → 城 → 关津        （可关）
上层  ：格网（LOD）                        （默认开，可关）
```

> 已修真 bug：`wetBands()` 原塞在 `surfaceCover()` 里，而它依赖的 `RIVER_GEO`
> 由 `river()` 填充，调用顺序在前，整个循环空转、河两岸是秃的。现已抽独立函数
> 放到水之后。

## 层次拆分

| 层 | 内容 |
| --- | --- |
| **背景层** | 纸、廓、连续场、林冠、灌丛、浅田、水、湿林带、题识 |
| **地物层** | 十二城郭、关津、桥舟、城外聚落田畴、烽燧 |
| **上层** | 格网；真接进主地图后还有势力色、部队、路线 |

背景层**不放任何居民点或点景建筑**。地物层的密由真实锚点派生：每处聚落挂在某座城或
关津上，朝向取最近河段切线角，`inDeepCanopy()` 用连续场避开郁闭深林。
城与城之间**不画任何路线**。

## 已知局限

1. 仍是「工笔化的舆图」而非严格工笔：短硬笔与分区薄罩做了，没做十八描线型分类。
2. 中低场区远看仍略带**点彩感**，放大到 ×3 以上更明显 —— 树冠团是一个个可辨的小团。
   下一步应让团随树种换笔型（针叶/阔叶/灌丛三套短笔），而不是只换色与尺寸。
3. 城外聚落仍是同规格小屋，可按城的性质（军屯 / 市邑 / 驿）换结构。
4. 支流两岸湿林带虽已打散，仍略像一条斜向划线，靠水名与水面区分。
5. 形象画法允许超比例压缩，投影不等比，题识已注明「纵横不拘实距」。
6. **LOD 阈值是演示值**：接进主地图时，`zoom` 应换成相机实际倍率，`.36/.69/.90`
   按真机像素密度再标一次；这段逻辑是纯函数，可直接搬到渲染层，不依赖存档。

## 与 v0.6.0 的关系

README 记录的「一笔山脊实验」结论要求「笔要读成受光的脊而不是沟，两侧皴法得顺着笔势
组织」。本实验不叠在任何格状层之上，且这一版进一步取消了「脊」这个可见物件。
**这是对照样本，不是结论** —— 是否替换 `buildBase()` 的静态层，仍需按仓库烟测口径
做 A/B。配色清单（v0.5.0 收尾）本轮仍未落地，`styles/main.css` 保持原样。
