## 层次拆分（最重要的一次修正）

这张图是给大地图当**底图**的，不是一张独立完整的文人山水。上一版把
城、关、塔、寺、亭、村舍、朱印、注记全画进同一个 canvas，还用
`poissonClusters` 全图随机撒 64 组**一模一样的三角符** + 若干图章函数复制，
结果密度来自重复而非地理，山体里甚至长出亭子 —— 既是层次错位，
也是最早说的「色块平铺」换了个花皮又犯一次。

现在按三层拆开：

| 层 | 内容 | 开关 |
| --- | --- | --- |
| **背景层**（本实验主体） | 纸、图廓、远山、泽、河、山、以及山自身的皴/苔/林/岩、河岸汀渚、水汊、泽缘芦苇、平原土脉 | 始终画 |
| **地物层** | 十二城郭、关津、桥舟、城外聚落与田畴、烽燧 | 「地物层」 |
| **上层** | 逻辑格网（144×108 tiles）、势力色、部队、路线 | 「压上格子」 |

- 背景层**不放任何居民点或点景建筑**；山里只有地貌。
- 地物层的「密」不再随机撒：每处聚落挂在某座城或某处关津上，间数、朝向、
  大小、注字由该城等级与最近河段的切线角连续决定，并 `inRidge()` 显式避开山体。
  烽燧挂在关口外侧，桥舟挂在真实河段上。
- 密集感在背景层改由**带 carry 状态的一次性游走**带出：沿山脚 / 河岸 / 泽缘 /
  平原，上一段的方向与终点决定下一段，笔数、长度、浓淡由局部坡度、曲率、
  离山距离连续给出 —— 密，但没有一个重复单元。

## 地理与山形

官渡一带是豫东平原，山只在西侧嵩箕、西北太行。上一版两条横贯全画的淡远山影
把中部也罩成「空灵山态」，不合实际，已收成西北一小段；中部改由低对比土脉与
水汊承担，不再空也不再假装有山。

四条山脊仍按四条意见重做：

1. **不往下垂成柱子**：峰高压到约 1/3（`amp = 26 + h*34`），山脚只出 10~16px
   横向赭色坡带，皴笔以横走为主、下垂限在 `amp*0.3` 内。
2. **线条不柔**：峰头显式折点、分段线性，峰顶是尖角不是圆弧；折带 / 斧劈走
   `hardRibbon()` 阶跃宽度；双勾 + 纸白水线 + 分区平涂逐层薄罩。
3. **山不是空剪影**：加深平涂与皴的对比，加密顺坡林带、折角岩块、山脚碎石、苔点。
4. **城与城之间不画任何线**：`ROADS` 只作逻辑锚点，不绘制路线。

另：用生成图作过一次对照微调（山形横向铺展、方硬折带、赭色坡脚、密符号、
河为细青双线、不画道路连线）。参考图仅作沙盒内对照，**未作为素材进入仓库**。

## 画法顺序

```
背景层：纸 → 图廓 → 远山 → 泽 → 河 → 山 → 地貌细节
地物层：桥舟 → 聚落田畴 → 城 → 关津        （可关）
上层  ：界格                                （可开）
```

数据锚点（十二城、汉末黄河故道、五条支流、三处泽薮、四条山脊、七处关津）
取自 `src/map-data.js` 的经纬度表，但**不遍历 `terrain.tiles`**，无重复单元、零位图。

- 河：双勾水线 + 极淡平涂；长河岸线切成**断续短笔**（笔断意连），否则一条贯穿画面的
  连续双线会读成道路或边界（实测诊断确认过这一点）。
- 城：界画双勾城墙、子城、门楼双层歇山、角楼、旗、垛口组内不等距、城内署廨、
  竖排名 + 等级朱印 + 小字注。城郭是古舆图「规格化的真形符号」，允许同一画法，
  但每个都有唯一实地位置。
- 关 / 津：三角关符 / 舟形渡符，按实地位置配置。

## 引入的第三方代码（已履行 MIT 义务）

`third-party/ink-stroke.js` 移植并改写了 `LingDong-/shan-shui-inf` 的 `stroke()/poly()`
与 `LingDong-/nonflowers` 的 `tubify()/stroke()/polygon()` 核心结构：
**沿点列按法向左右推宽度 → 闭合多边形一次 fill**。
两项目均为 `MIT License, Copyright (c) 2018 Lingdong Huang`，许可全文随包保留，
文件头保留版权声明。改动清单见 `ATTRIBUTION.md`。

`hardRibbon / hardProfile`（方折/斧劈）、`doubleOutline`（双勾水线）、`flatWash`
（分区平涂）、`terrainDetail()` 的游走生成、`settlements()` 的地理派生、
以及全部地物生成逻辑，均为本仓库自撰。

## 已知局限

1. 仍是「工笔化的舆图」而非严格工笔：分区平涂与双勾做了，没做十八描线型分类，
   也没做矿物/植物颜料的物理扩散。
2. 城外聚落虽已按地理参数逐个生成，远看仍略像同规格小屋 —— 古舆图本身用
   规格化符号，但若要更活，下一步应让屋舍随所属城的性质（军屯 / 市邑 / 驿）
   换结构，而不是只换参数。
3. 长支流断续后仍略像虚线路径，靠水纹、水汊与竖排水名区分。
4. 形象画法允许超比例压缩，投影不等比，题识已注明「纵横不拘实距」。
5. 背景层刻意偏淡：它是给上层压格子 / 势力色用的底，太浓会抢戏。
   单独看会略素，配上地物层才是成品。

## 与 v0.6.0 的关系

README 记录的「一笔山脊实验」把一条暗笔叠在格状皴之上，实拍读成划痕，
结论要求「笔要读成受光的脊而不是沟，两侧皴法得顺着笔势组织」。
本实验不叠在任何格状层之上，而是整幅另起：脊线提光、皴笔顺坡、明度由脊向外渐暗。
**这是对照样本，不是结论** —— 是否替换 `buildBase()` 的静态层，仍需按仓库烟测口径
做 A/B 后再定。配色清单（v0.5.0 收尾）本轮仍未落地，`styles/main.css` 保持原样。
