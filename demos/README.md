**离线整幅重绘实验**，不接入 `src/`，不修改 `terrain.js` / `map-data.js` / 存档 / 策略层，
也不触碰 `?brush=on` 的 A/B 开关与 `renderer.setBrush()`。

## 本版按四条意见重做

1. **山不再往下垂成柱子**：峰高压到原来的约 1/3（`amp = 26 + h*34`），山脚只出
   10~16px 的横向赭色坡带，坡脚用断续横短线暗示而不画实线；皴笔以横走为主，
   末端只作一次短方折，下垂长度限制在 `amp*0.3` 以内。
2. **线条不再柔**：峰头改成显式折点、分段线性，峰顶是尖角不是圆弧；轮廓、皴、
   斧劈走 `hardRibbon()` 的阶跃宽度函数；双勾 + 纸白水线，分区平涂逐层薄罩，
   不靠大面积柔和渐变。
3. **不再太空**：补了三角符、塔、寺、村舍、烽燧、田畴斜排短线组、拱桥、舟、
   朱印、小字竖注，按「锚点簇 + 最小间距」散布（**不是均匀网格平铺**），
   密度取法《平江图》「多而不乱」。
4. **城与城之间不画任何线**：`ROADS` 只保留为符号簇的锚点，不绘制路线。
   这张图就是**背景**，逻辑格网由上层直接叠压；「压上格子」按钮只是预览这个叠法，
   默认不画。

另：用生成图作了一次对照微调（山形横向铺展、方硬折带、赭色坡脚、密小符号、
河为细青双线、不画道路连线），据此调整了上面几处参数。参考图仅作沙盒内对照，
**未作为素材进入仓库**。

## 画法顺序

纸 → 图廓 → 远山 → 泽 → 河 → 山 → 桥舟 → 密符号 → 城 → 关津 → 界格（可选）。

数据锚点（十二城、汉末黄河故道、五条支流、三处泽薮、四条山脊、七处关津）
取自 `src/map-data.js` 的经纬度表，但**不遍历 `terrain.tiles`**，无重复单元、零位图。

- 河：双勾水线 + 极淡平涂；长河岸线切成**断续短笔**（笔断意连），否则一条贯穿画面的
  连续双线会读成道路或边界（实测诊断确认过这一点）。
- 城：界画双勾城墙、子城、门楼双层歇山、角楼、旗、垛口组内不等距、城内署廨、
  竖排名 + 等级朱印 + 小字注。
- 关 / 津：三角关符 / 舟形渡符，按实地位置配置。

## 引入的第三方代码（已履行 MIT 义务）

`third-party/ink-stroke.js` 移植并改写了 `LingDong-/shan-shui-inf` 的 `stroke()/poly()`
与 `LingDong-/nonflowers` 的 `tubify()/stroke()/polygon()` 核心结构：
**沿点列按法向左右推宽度 → 闭合多边形一次 fill**。
两项目均为 `MIT License, Copyright (c) 2018 Lingdong Huang`，许可全文随包保留，
文件头保留版权声明。改动清单见 `ATTRIBUTION.md`。

`hardRibbon / hardProfile`（方折/斧劈）、`doubleOutline`（双勾水线）、`flatWash`
（分区平涂）、以及全部地物生成逻辑，均为本仓库自撰。

## 已知局限

1. 仍是「工笔化的舆图」而非严格工笔：分区平涂与双勾做了，但没做真正的十八描线型
   分类，也没做矿物/植物颜料的物理扩散。
2. 长支流断续后仍略像虚线路径，靠水纹与竖排水名区分；若接回 `src/` 可再压淡。
3. 形象画法允许超比例压缩，投影不等比，题识已注明「纵横不拘实距」。
4. 城郭在中部有几处叠压，古图亦有此现象，未做自动避让。

## 与 v0.6.0 的关系

README 记录的「一笔山脊实验」把一条暗笔叠在格状皴之上，实拍读成划痕，
结论要求「笔要读成受光的脊而不是沟，两侧皴法得顺着笔势组织」。
本实验不叠在任何格状层之上，而是整幅另起：脊线提光、皴笔顺坡、明度由脊向外渐暗。
**这是对照样本，不是结论** —— 是否替换 `buildBase()` 的静态层，仍需按仓库烟测口径
做 A/B 后再定。配色清单（v0.5.0 收尾）本轮仍未落地，`styles/main.css` 保持原样。
