## 视角：空中俯瞰，只看见树，看不见山

前几版一直在画「山形剪影」——峰头、立面、折带皴、山脚坡带。俯瞰视角下
**画面里根本不该有"山"这个物件**：从上看下去只有连续郁闭的林冠，山的走向
只能由林冠的明暗起伏、树种深浅、沟谷里更暗的林带**被读出来**。

这一版删掉了：

- `ridge()` 整个山形绘制（峰头折点、分区平涂、双勾水线、折带/斧劈皴、苔点、山脚坡带）
- `farHills()` 的远山剪影（航拍没有地平线、没有远山）
- `terrainDetail()` 里所有「山内」逻辑

`RIDGES` 四条数据不再是「要画的山」，只是**地形场的隆起轴**，名字也改成
嵩箕林 / 箕山坞 / 太行林 / 历山坞。

## 连续地形场，不是格网

`buildField()` 预采样一张 241×177 的场图（`FIELD / WET / OPEN`），查询用双线性插值：

```
E = Σ 脊轴高斯隆起 − 河谷/泽薮下切 + 三层低频连续起伏 − 城外清场
W = 到最近水系的湿度
O = 城外浅田环 / 沙洲 / 图廓内侧的「留白意愿」
```

场图只是**连续函数的采样缓存**，不参与绘制决策的重复单元。所有笔触位置由
「带 carry 的不等距扫描游走」给出，不遍历场图格子。

配色由 `(E, W, 受光)` 连续给出：深林墨青 → 中林汁绿 → 灌丛橄榄 →
草甸赭黄 → 城外浅田。低场区也要铺，只是色浅笔疏——**浅田是笔，不是纸**。

## 面覆盖，不是线簇

第一版让游走带沿等值线跑，结果带全被梯度吸到高场区聚成条，中间空出大片纸
（露纸率实测 **59%**）。航拍不是线簇，是一遍笔把地表写完。

改成**不等距扫描式面覆盖**：行距、步长、密度、色、笔势全由连续场 + 沿行/跨行
传递的 `carry` 决定；行不跟梯度跑，只做小幅场起伏。再叠三套不同方向的游走
（斜向灌丛、短硬笔织面、湿林带）打散任何条纹感。每个树冠团当场由场值生成
3~6 个方硬短笔并合成一条路径一次 fill，**没有任何可复制的图章函数**。

实测露纸率（1400×1100 实拍，统计 RGB 近纸色像素）：

| 状态 | 露纸 |
| --- | --- |
| 只看背景 | **10.4%** |
| 完整图 | **11.7%** |

白只从**笔缝、泽中沙洲、城外浅田环、图廓内侧**漏出来，是碎的、一丢丢，
不是成片空场。上面足够密，眼睛不会往下找底 —— 这是「看不见白底」的意思，
不是把纸盖住。纸底保留，只压低了对比。

## 修掉的一个真 bug

`wetBands()`（河/泽两岸的深青湿林）原来塞在 `surfaceCover()` 里，而它依赖的
`RIVER_GEO` 由 `river()` 填充，**调用顺序在前，整个循环空转**，河两岸因此是秃的。
现已抽成独立函数，放在水画完之后调用。

绘制顺序：

```
背景层：纸 → 图廓 → 建场 → 林冠面覆盖 → 泽/河（盖在林上） → 湿林带
地物层：桥舟 → 聚落田畴 → 城 → 关津        （可关）
上层  ：界格                                （可开）
```

## 层次拆分（保留）

| 层 | 内容 |
| --- | --- |
| **背景层** | 纸、廓、连续场、林冠、灌丛、浅田、水、湿林带 |
| **地物层** | 十二城郭、关津、桥舟、城外聚落田畴、烽燧 |
| **上层** | 逻辑格网（144×108 tiles）、势力色、部队、路线 |

背景层**不放任何居民点或点景建筑**；山里（现在该说林里）只有地貌。
地物层的密由真实锚点派生：每处聚落挂在某座城或关津上，朝向取最近河段切线角，
`inDeepCanopy()` 用连续场避开郁闭深林。城与城之间**不画任何路线**。

城外浅田环改成断续田埂短笔，不再填实心椭圆（贴纸感太重）；城名按所在场值
切深/浅字并加反向描边，保证密背景上读得出。

## 已知局限

1. 仍是「工笔化的舆图」而非严格工笔：短硬笔与分区薄罩做了，没做十八描线型
   分类，也没做矿物/植物颜料的物理扩散。
2. 中低场区远看仍略带**点彩感**——树冠团是一个个可辨的小团。若要更贴工笔，
   下一步应让团随树种换笔型（针叶/阔叶/灌丛三套短笔），而不是只换色与尺寸。
3. 支流两岸的湿林带虽已打散，仍略像一条斜向划线，靠水名与水面区分。
4. 城外聚落仍是同规格小屋，古舆图本用规格化符号，但下一步可随城的性质
   （军屯 / 市邑 / 驿）换结构。
5. 形象画法允许超比例压缩，投影不等比，题识已注明「纵横不拘实距」。
6. 背景层刻意铺得很密，是给上层压格子 / 势力色用的底；单独看略素属正常，
   配上地物层才是成品。

## 与 v0.6.0 的关系

README 记录的「一笔山脊实验」把一条暗笔叠在格状皴之上，实拍读成划痕，
结论要求「笔要读成受光的脊而不是沟，两侧皴法得顺着笔势组织」。
本实验不叠在任何格状层之上，而是整幅另起，且这一版进一步取消了「脊」这个
可见物件：起伏由林冠明度承担。**这是对照样本，不是结论** —— 是否替换
`buildBase()` 的静态层，仍需按仓库烟测口径做 A/B。配色清单（v0.5.0 收尾）
本轮仍未落地，`styles/main.css` 保持原样。
