# 矢量文件辨识 · 唯一权威口径

> 这份文档只回答一件事：**为什么你打开的那份《建安五年全境舆图》看着像「地图退化」，
> 以及当前该看哪一份。** 之前在 `README-全境.md` 里散落过五处解释，全部收敛到这里。

## 一、三份东西，别混

| | 是什么 | 会不会更新 |
|---|---|---|
| **你手上那份链接**（标题「建安五年全境舆图 · **矢量骨架**」，正文只有一串连着的地名、没有山川地貌） | 早期某次交付时上传到平台的**快照**。当时文件只画了图廓 / 州界 / 水系 / 城邑 / 格网 / 注记（79 path / 166 text），地貌笔触还在页面运行时画、没进文件 | **永远不会自动更新**。改仓库、改文件名、重新推送，都改不了那个链接里的内容 |
| **仓库里的 `demos/建安五年全境舆图-全量矢量.svg`** | 当前唯一权威的全量矢量图 | 随仓库更新 |
| **demos 工具条「导出矢量」** | 按当前视图即时生成，下载名也是 `建安五年全境舆图-全量矢量.svg` | 每次都是当场生成 |

## 二、混淆的真正根因

早期那份骨架的文件名叫 **`atlas-vector.svg`**。
后来仓库把**同名文件**换成了全量版，但**你手上那份平台快照的名字没变**。
于是「同一个名字，两份完全不同的内容」——我每轮回一句「仓库当前已是全量」，
对你没用，因为你打开的是自己那个链接，不是仓库。

所以解法不是再解释一遍，而是：
- 明确命名、单独交付（就是这份 `-全量矢量.svg`）
- 文件自带自证，打开就能当场判定（见下）
- **平台旧链接请直接弃用**，别拿它判断地图有没有退化

## 三、当场判定（三秒）

打开 SVG 看 `<title>` / `<desc>`，或直接数标签：

| 判定 | 骨架（旧） | 全量（当前） |
|---|---|---|
| `<title>` | `建安五年全境舆图 · 矢量骨架` | `建安五年全境舆图 · 全量矢量` |
| `<desc>` | 「地貌笔触层由页面运行时路径绘制，不烘焙进位图」 | 「全量矢量（非骨架）……均为 path·rect·text 矢量指令，无位图」 |
| `<path>` 数 | 79 | **4533**（本轮审美复审后重导出，详见文末） |
| `<rect>` 数 | 0 | **5**（连续渐变底罩，不再是 15401 个色块） |
| `<text>` 数 | 166 | **106**（84 处注记，已自动避让） |
| `<image>` | 0 | **0**（都不含位图，这条不能用来区分） |
| 画面 | 一串孤立地名铺在纸上 | 完整全境：南北异风、长城三重、水系、州界、城邑、题识、格网 |

`<desc>` 里还写了一句自证：

> 若单独打开只看到一串孤立地名而无地貌，那是早期「矢量骨架」旧快照，不是本文件。

**判定以 `<title>` / `<desc>` 为准，不要死记 path 数**：全量图的笔数会随
笔法迭代变化（本轮从 6144 降到 4533），骨架与全量的差别始终是「只有地名」
对「有完整地貌笔路」。

## 四、当前文件清单

- `demos/建安五年全境舆图-全量矢量.svg` —— **权威交付，用这个**
- `demos/atlas-vector.svg` —— 历史同名文件，内容已与上面**逐字节相同**（sha256
  `ea34abeb…`，本轮重导出后已换）。保留只为不破坏已有引用，**不要再用这个名字对外交付**
- `demos/建安五年全境舆图.html` —— 页面本体；「导出矢量」按钮下载的是权威命名那份

两份全量文件当前都是 `4533 path / 5 rect / 106 text / 0 <image>`，
可无限放大、不含任何位图、不压格网。

### 本轮为什么又改了这两份文件

上一轮我写过「两份全量 SVG 逐字节相同、**一个字节不动，它们是正确的**」——
这句把「技术正确」当成了「审美正确」，是错的。实拍里它们带着格网线（读成
坐标纸）、15400 个色块底罩露出的南北水平断层、以及满纸等密度撒笔，并不好看。
本轮按审美复审重导出：底罩换连续渐变、撒笔改低频簇场聚散、交付图不压格网。
**文件内容变了、文件名没变**；平台上的旧快照仍然不会随之更新，请继续用本页
的 `<title>` / `<desc>` 判定，别拿旧链接里的数字对比。

## 五、一句话

> **你贴的那份是平台快照，不是仓库文件，也不会随仓库变。**
> 要判断地图，请打开本次交付的 `建安五年全境舆图-全量矢量.svg`，
> 或页面里点「导出矢量」。旧链接弃用即可。

## 六、第十七轮之后：皮肤与 desc

现在文件里 `<metadata>` 带 `skin`（`classic` / `landscape`），`<desc>` 开头
也写明皮肤名。**判定骨架 / 全量仍只看 `<title>` 与「有没有地貌笔路」**，
不看 path 数、不看皮肤、不看 rect 数——这些都会随皮肤与笔法迭代变。

- 仓库里 `demos/atlas-vector.svg` 与 `demos/建安五年全境舆图-全量矢量.svg`
  固定为 **`classic` 基线**，不随页面皮肤切换改变，是回退锚点。
- 大改候选单独放 `demos/skins/形象画法候选.svg`（新名字，不与旧快照同名），
  它的 `<title>` 同样写着「全量矢量」，`<desc>` 会标明皮肤是「形象画法（大改候选）」。
- 备份快照是 `demos/skins/写意底图-备份基线.svg`。

**再强调一次**：你手上那个 `userassets` 链接里的「矢量骨架」是平台旧快照，
不会随仓库更新；判断当前画面请用本页新链接或 demos 页面里的皮肤下拉。
